# 최종 발표 결과물

사용자의 2026-10-27 커밋·푸시 지시에 따라 최종 영상·음성·자막·크레딧·품질 기록을 게시한다.
최신 전체 발표 영상은 `ARD_FullPresentation_1080p_v2.mp4`이며, 이전 버전도 보존한다.
음악·음향·나레이션 출처는 각 `CREDITS` 파일을 따른다.
크레딧의 로컬 추론 설명은 음성 생성 과정에 관한 것으로, 이번 최종 결과물 게시와 구분한다.

MP4/WAV 실제 데이터는 Git LFS에 저장한다. 저장소를 받은 후 파일이 작은 텍스트 포인터로 보이면 다음을 실행한다.

```powershell
git lfs install
git lfs pull
```

원본 음성 학습 자료·학습 모델·다운로드 음원 원본·렌더 캐시는 이 폴더에 포함하지 않는다.
