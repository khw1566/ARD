## 기구학 모델의 정의

현재 PC 코드의 `gearAngleX = yawAngle + rollAngle`, `gearAngleY = yawAngle - rollAngle` 관계와 CAD의 마주 보는 입력축 구조를 기준으로 한다.

- `θA`, `θB`: 모터 각도. 실물 축의 양의 방향을 확인해 같은 제어 기준으로 정규화한다.
- `iA`, `iB`: 각 감속기의 입력각/출력각 비.
- `a = θA / iA`, `b = θB / iB`: 감속 후 베벨 입력축의 정규화된 각도.
- `ψ`: 플레이트의 자기 축 주위 선회각.
- `φ`: 공통 입력축 주위 기울임각.

동일한 베벨기어비를 갖는 이상적인 기구 모델은 다음과 같다.

```text
ψ = (a + b) / 2
φ = (a - b) / 2

역기구학:
a = ψ + φ
b = ψ - φ

모터 목표각:
θA = iA × (ψ + φ)
θB = iB × (ψ - φ)
```

| 정규화된 입력 | 출력 |
|---|---|
| a=q, b=0 | ψ=q/2, φ=q/2 |
| a=0, b=q | ψ=q/2, φ=-q/2 |
| a=q, b=q | ψ=q, φ=0 |
| a=q, b=-q | ψ=0, φ=q |

두 모터는 마주 보므로 각 모터를 정면에서 보았을 때의 시계·반시계 방향을 단순히 ‘같은 방향’이라고 부르지 않는다. 영상의 A/B 입력은 정규화된 제어 부호를 뜻한다. 현재 CG의 고정 좌표 X는 입력축, Y는 중립 상태의 출력축이다. 출력 자세는 입력축 기울임 뒤 출력축 자체 선회를 표현하는 `R_X(φ) R_Y(ψ)`로 구성했다.

시각화는 강체·동일 베벨기어비·이상적인 전달을 가정한다. 유성감속기의 4:1 구성은 사용자 확인값이며, 실제 설치된 베벨 축 부호, 치형의 접촉·백래시·하중·탈조는 이번 미리보기로 검증하지 않았다. 애니메이션의 예시 각도를 실제 운전 범위나 측정 성능으로 주장하지 않는다.

추가 CAD는 지금 바로 필요하지 않다. 다음 정보가 있으면 기구학 설명의 실제 축 부호·수치를 확정할 수 있다.

1. **모터 방향 확인:** A만 양의 명령, B만 양의 명령, 두 축 같은 부호, 두 축 반대 부호일 때 플레이트가 움직이는 방향. 짧은 CAD 구동 영상이나 화살표를 그린 그림으로도 충분하다.
2. **베벨기어비:** 유성감속기의 잇수 16/16/48과 4:1 구성은 확인 완료. 차동 베벨기어의 잇수·기어비와 각 축 설치 부호는 추가 확인 대상이다.
3. **개인 TTS:** 로컬 myTTS 모델로 15컷의 합성과 음량·길이 맞춤을 완료했다. 발음과 편집 수정 시 최신 v4 대본 및 `narration/manifest.json`을 기준으로 한다.
