## 이번 스타일 수정

사용자는 Blue Paw Print에서 배경·재질·단면 표현을 참고하되 그대로 따라 하지 말라고 지정했다. 참고 채널과 `Inside the King Tiger`의 공개 재생 화면을 확인했다. 이번 구성은 장치에 맞춘 별도의 스튜디오 배경, 조명, 금속·수지 재질과 입력축 색상 체계를 사용한다. 참고 영상의 모델·텍스처·로고·음원은 가져오지 않았다.

- 밝은 문서형 화면을 대신해 깊이가 보이는 스튜디오 바닥·배경과 따뜻한 주광·차가운 보조광을 적용했다.
- 브러시드 금속, 수지 표면의 절차적 질감, 표면 반사와 그림자를 추가했다.
- STL 곡면의 음영을 보완하되 기어 치형과 테두리의 날카로운 경계는 유지했다. 실제 삼각형의 위치·크기는 바꾸지 않았다.
- 외피 단면으로 감속기·차동 기어를 드러내고, 기어 맞물림을 확대하는 구도로 전환한다.
- 외피를 절단한 면에는 별도의 단면 해칭을 적용한다. 내부 기어는 절단하지 않아 입력·출력의 맞물림을 계속 볼 수 있다.
- 모터 A 입력 계열은 황동색, B 입력 계열은 청색으로 구분한다. 설명을 위한 색상이며 실물 재질·색상의 측정 결과는 아니다.
- 기어 상세 설명 때에는 접시를 숨겼다가 카메라를 뒤로 빼며 다시 표시한다. 내부 전달과 최종 자세를 이어서 볼 수 있다.
- 원형 접시는 회전해도 외형이 같아 보일 수 있어, 확대 장면에 선회 방향을 보여주는 설명용 화살표를 겹쳐 표시한다. CAD에 실제 부품을 추가한 것은 아니다.

## 기구학 모델의 정의

현재 PC 코드의 `gearAngleX = yawAngle + rollAngle`, `gearAngleY = yawAngle - rollAngle` 관계와 CAD의 마주 보는 입력축 구조를 기준으로 한다.

- `θA`, `θB`: 모터 각도. 실물 축의 양의 방향을 확인해 같은 제어 기준으로 정규화한다.
- `iA`, `iB`: 각 감속기의 입력각/출력각 비.
- `a = θA / iA`, `b = θB / iB`: 감속 후 베벨 입력축의 정규화된 각도.
- `ψ`: 플레이트의 자기 축 주위 선회각.
- `φ`: 공통 입력축 주위 기울임각.

동일한 베벨기어비를 갖는 이상적인 기구 모델은 다음과 같다.

```text
ψ = (a + b) / 2
φ = (a - b) / 2

역기구학:
a = ψ + φ
b = ψ - φ

모터 목표각:
θA = iA × (ψ + φ)
θB = iB × (ψ - φ)
```

| 정규화된 입력 | 출력 |
|---|---|
| a=q, b=0 | ψ=q/2, φ=q/2 |
| a=0, b=q | ψ=q/2, φ=-q/2 |
| a=q, b=q | ψ=q, φ=0 |
| a=q, b=-q | ψ=0, φ=q |

두 모터는 마주 보므로 각 모터를 정면에서 보았을 때의 시계·반시계 방향을 단순히 ‘같은 방향’이라고 부르지 않는다. 영상의 A/B 입력은 정규화된 제어 부호를 뜻한다. 현재 CG의 고정 좌표 X는 입력축, Y는 중립 상태의 출력축이다. 출력 자세는 입력축 기울임 뒤 출력축 자체 선회를 표현하는 `R_X(φ) R_Y(ψ)`로 구성했다.

시각화는 강체·동일 베벨기어비·이상적인 전달을 가정한다. 실제 감속비, 축 부호, 치형의 접촉·백래시·하중·탈조는 이번 미리보기로 검증하지 않았다. 애니메이션의 임의 예시 각도를 실제 운전 범위나 측정 성능으로 주장하지 않는다.

## 첨부 자료 확인과 활용

- 전체 조립품·박스 제거·비전캠 제거·상하부 이송부 STL을 확인했다.
- 추가된 `한방향 베벨기어만(A).stl`, `한방향 베벨기어만(B).stl`, `양측 베벨기어만.stl`, `구동축 베벨기어와 접시만.stl`로 입력·출력 부품의 역할을 확인했다.
- 기존 전체 조립 상태와 좌표·면이 일치하는 메쉬를 분리해 A/B 입력, 출력축·중앙 연결부, 반대편 기어, 접시를 각각 구동한다. 별도 내보내기 사이에 미세한 자세 차이가 있어 한 조립 상태의 면 집합을 기준으로 맞췄다.
- `조립품에서 가져온 원점유지 감속기.stl`이 추가된 것을 확인했다. 별도 유성기어 감속기 파일은 원점이 달라 전체 조립체에 그대로 중복 배치하지 않는다.
- 감속기 참고 영상 두 개와 `리니어 스크류 구동.mp4`의 재생 정보와 프레임을 확인했다. 이들은 구조 참고 자료이며 완성 영상에 그대로 삽입한 촬영본은 아니다.
- 상세 목록·경계 좌표·파일 유효성은 `cad_inventory.json`, 영상 정보는 `video_inventory.json`에 기록했다.

## 추가로 필요한 정보

추가 CAD는 지금 바로 필요하지 않다. 다음 정보가 있으면 기구학 설명의 실제 축 부호·수치를 확정할 수 있다.

1. **모터 방향 확인:** A만 양의 명령, B만 양의 명령, 두 축 같은 부호, 두 축 반대 부호일 때 플레이트가 움직이는 방향. 짧은 CAD 구동 영상이나 화살표를 그린 그림으로도 충분하다.
2. **감속비:** A/B 감속기의 실제 감속비. 알고 있다면 선기어·유성기어·링기어 잇수도 함께 제공. 동일 베벨기어비인지도 확인하면 좋다. 모르는 값은 확정 수치로 넣지 않는다.
3. **개인 TTS:** 화면 스타일과 기술 설명을 다듬은 뒤 아래 대본으로 컷별 WAV를 제작하면 된다. 현 단계에서는 음원이 없어도 CG를 계속 수정할 수 있다.
