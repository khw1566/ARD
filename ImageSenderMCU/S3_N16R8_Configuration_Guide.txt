# ESP32-S3-N16R8 Configuration Guide for PlatformIO

## 1. Board Specifications
- Core: ESP32-S3
- Flash: 16MB (Quad SPI)
- PSRAM: 8MB (Octal SPI)
- Interface: Dual USB (UART/USB)

## 2. PlatformIO Configuration (platformio.ini)
This configuration is critical for N16R8 models to prevent boot loops and ensure PSRAM detection.

```ini
[env:esp32-s3-n16r8]
platform = espressif32
board = esp32-s3-devkitc-1
framework = arduino
monitor_speed = 115200

build_flags = 
    -DBOARD_HAS_PSRAM
    -DCORE_DEBUG_LEVEL=3
    -DARDUINO_USB_MODE=1
    -DARDUINO_USB_CDC_ON_BOOT=0 ; Set to 0 to use Hardware UART port for Serial logs

board_build.arduino.memory_type = qio_opi ; Critical for N16R8 (Quad Flash, Octal PSRAM)
board_build.flash_mode = qio
board_build.psram_type = opi
board_build.f_flash = 80000000L
board_build.f_cpu = 240000000L
board_upload.flash_size = 16MB
```

## 3. Important Stability Fixes (Code Level)

### Brownout Diagnosis
Retain SDK brownout protection. Do not directly clear RTC_CNTL_BROWN_OUT_REG.
Arduino-only builds use a precompiled SDK; sdkconfig.defaults does not rebuild it.
Use the diagnostic environments described in POWER_DIAGNOSTIC.md to separate
Flash/PSRAM startup from application initialization. The application prints
Boot Stage 1-4 and the camera driver's return code to locate failures.

### Serial Monitoring
- Missing setup() logs can indicate early startup failure or Serial routing issues.
- Use `ARDUINO_USB_CDC_ON_BOOT=0` to force output to the Hardware UART.
- Use `ARDUINO_USB_CDC_ON_BOOT=1` to use the Native USB port (requires switching cables/ports).

## 4. Camera Pin Mapping (Standard S3-CAM)
Verified pinout for most S3 camera modules:
- XCLK: 10, PCLK: 13, VSYNC: 6, HREF: 7
- SDA: 4, SCL: 5
- Data: D0:11, D1:9, D2:8, D3:10, D4:12, D5:18, D6:17, D7:16 (Check specific board if this fails)
- **Note**: The camera initialization fails if `xclk_freq_hz` is too high during power-unstable states. Start with 10MHz or 20MHz.
