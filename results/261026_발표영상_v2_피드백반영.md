## 다섯 가지 피드백 반영

1. **이중 자막·문장 불일치:** 최종 MP4에 mov_text를 포함하지 않는다. HTML에도 자동 자막 track을 넣지 않았다. `build_captions.py`가 측정된 음성 구간과 실제 나레이션 문장으로 `narration/cg_captions.json`을 만든다. PC·DriveMCU·A/B·0·4 : 1 같은 용어는 표기형으로 통일한다. 화면과 외부 SRT가 같은 큐를 사용한다. 문장/쉼표 단위의 시간 배분은 글자 수 비율이며 단어별 강제 정렬은 아니다.
2. **모니터 노출:** 두 PC 화면에 강한 블러와 프레임별 마스크를 적용했다. 플레이트가 화면 앞을 지날 때는 흰색 전경의 연결 영역·볼록 윤곽을 추적해 기구를 가림에서 제외한다. 이메일·AI 채팅 화면은 읽을 수 없도록 처리했다. 12개 실물 시점에서 확인했으며 모든 프레임의 수동 개인정보 검수를 주장하지 않는다. 최종 두 MP4의 촬영 위치 태그도 제거했다.
3. **크레딧 중복:** 실물 구간에 음악 크레딧을 넣지 않는다. 전체 발표의 마무리에서 한 번만 표시한다. 단독 시연은 별도 크레딧 파일과 재생 페이지에서 출처를 제공한다.
4. **동작과 대사 불일치:** 115–129초 CG 장면에서 레일 이송(30mm), 플레이트 선회, 기울여 배출, 중립 자세, 레일 복귀를 순서대로 수행한다. 카메라는 고정한다. 840개 구간 표본에서 레일 변화와 플레이트 입력 변화가 겹치지 않는지 검사했다. 30mm는 설명 애니메이션의 이동량이며 실측 장치 성능이나 실제 선별 위치 보정값이 아니다.

## 구현과 재출력

- `cinematic.html`, `cinematic.js`, `cinematic_plan.js`, `cinematic_v2.css`: 최신 미리보기. 기존 `cinematic.css`는 이전 스타일 기록으로 보존한다.
- `editorial_overlay.js`: 미리보기/출력의 공통 캔버스 그림. 외부 폰트를 SVG foreignObject에 다시 싣지 않아도 화면과 내보내기가 일치한다.
- `fonts/`: IBM 공식 및 Google Fonts 저장소에서 내려받은 서체, OFL, URL·SHA-256 기록. 시스템 서체를 설치하지 않았다.
- `export_v2.html`, `export_video_v2.js`: 소개 390프레임+CG 3630프레임을 WebGL/WebCodecs로 직접 인코딩한다. 총 4020프레임을 약 21.86초에 출력했다. 원래 3D 기구 리그와 CAD는 유지했다.
- `render_server.py`: 127.0.0.1 전용 수신기. 이번 정상 job은 `render_jobs/20261026-213804/`다. 권한 제한 환경의 5188 시도는 브라우저에서 연결할 수 없어 정상 수신기는 5189로 실행했다.
- `make_presentation_v2.py`: 실물 전경 마스크 영상, 자막 PNG 오버레이, 마무리, 기존 오디오 믹스를 연결한다. 소개/CG 134초+실물 42.267초+마무리 3.733초다. `--prepare-only`는 오버레이/검수 이미지만 만들고 `--reuse-renders`는 같은 job의 CG와 마스크 영상이 이미 있을 때만 사용한다.
- 원래 `export_video.js`도 새 공통 캔버스 오버레이를 읽도록 맞췄다. v2 전체 발표 출력의 진입점은 `export_v2.html`이다.

재출력 순서:

```powershell
python output/ard-cg/build_captions.py
$env:ARD_RENDER_PORT='5189'
python output/ard-cg/render_server.py
# 브라우저에서 http://127.0.0.1:5189/export_v2.html 을 열어 렌더링한다.
# 다음 명령은 다른 터미널에서 렌더 완료 후 실행한다.
python output/ard-cg/make_presentation_v2.py
node output/ard-cg/verify_v2_content.cjs
python output/ard-cg/verify_presentation_v2.py
```

원래 개인 음성·오디오 믹스·가공된 STL·FFmpeg가 필요하다. `apply_v2_source.py`는 이미 적용한 일회성 마이그레이션 기록이며 다시 실행하지 않는다. 프로젝트 메모리나 사용자 전역 설정을 수정하지 않았다.
