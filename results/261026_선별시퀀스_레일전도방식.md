# 선별 시퀀스: 레일 이송 + 전후진 전도 방식

## 변경 요약

자동 선별은 디스크 선회를 쓰지 않는다. 레일 이송과 트레이 전진/후진 전도만 사용한다.
재질별 배출 위치는 코드에 고정하지 않고, 수정 가능한 **배출 위치 표**(레일 설정 파일 `ARD_MAIN/backend/rail_calibration.json`의 `destinations`, `tilt_deg`)에서 읽는다.

## 새 단계

| 단계 | 내용 |
|---|---|
| 1 초기화 | 상태 확인 → (PID 모드) 레일 촬영 위치 → 트레이 X/Y 원점 |
| 2 촬영 | 새 이미지 촬영·수신 |
| 3 AI 분석 | 재질 분류 |
| 4 레일 이송 | 표의 레일 위치(+측/중앙/-측)로 이동. PID 모드는 저장된 ToF 거리, 개루프는 ±15 mm(중앙 0) |
| 5 전도 배출 | 표의 방향으로 전도(기본 45°), 2초 낙하 대기 |
| 6 복귀 | 전도 복귀(수평) → 레일 촬영 위치(개루프는 시작 스텝) |

전도 명령: 전진 = `b{+r},{-r}`(df 방향), 후진 = `b{-r},{+r}`. r = 각도/1.8 × 감속비. 선회(`dr`/`dl`, 같은 부호 `b` 이동)는 보내지 않는다.

## 기본 배출 위치 표 (추정값, 반드시 확인 필요)

이전 배치에서 선회 90° → 전진, 270° → 후진으로 바꿔 만든 **추정값**이다. 사용자가 "낙하 위치가 다르게 나온다"고 했으므로 실기에서 [배출 위치 시험]으로 확인해야 한다.

| 재질 | 레일 위치 | 전도 방향 |
|---|---|---|
| Metal (금속/캔) | +측 | 전진 |
| Glass (유리) | -측 | 전진 |
| Others (기타) | -측 | 전진 |
| Paper (종이/팩) | +측 | 후진 |
| Plastic (플라스틱) | -측 | 후진 |

전도 각도 기본값은 45°(5~90°)이다.

## 표를 고치는 방법

1. PC 프로그램 → 구동 보드 탭 → "Z축 레일 측정·레벨링 도구" 카드 → **⑤ 배출 위치 표**.
2. 트레이 X/Y가 원점인지 확인한다(아니면 선별 [초기화 / 재시도 준비]).
3. 재질 행의 **[배출 위치 시험]**을 누른다. 레일 이동 → 전도 → 2초 대기 → 전도 복귀 → 레일 중앙(PID 끔) 순서로 움직인다. 카메라·AI는 쓰지 않는다. 선별 중이거나 다른 레일 도구가 실행 중이면 거부된다. [도구 중단] 또는 비상정지로 멈출 수 있다.
4. 원하는 배출함에 떨어지지 않으면 레일 위치·전도 방향을 고치고 **[배출 위치 표 저장]** 후 다시 시험한다.
5. 저장한 표는 다음 선별부터 적용된다. 사이드바 "배출 위치" 안내, 3D 배출함 색·위치, JC1060 메인 화면 배출함 칸이 표를 따른다.

API: `POST /api/rail/config {"destinations": {...}, "tilt_deg": 45}`, `POST /api/rail/test-drop {"category": "Metal"}`.
