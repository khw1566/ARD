# CG 유성감속 원리 설명과 카메라 개편

2026-10-26, 한국 시간. 빌드와 실물 구동 없이 CG 소스·파생 메쉬·브라우저 미리보기만 변경했다.

## 사용자 확인 사항과 감속 원리

사용자가 태양/행성/링 잇수 **16/16/48**, **링 고정, 태양 입력, 캐리어 출력**을 직접 확인했다. 제공된 CAD·참고 영상에는 행성기어가 네 개 있다.

태양기어가 행성기어를 구동할 때, 행성기어는 고정 링과의 맞물림도 동시에 만족해야 한다. 그래서 기어 자체의 자전과 중심축의 공전이 함께 발생한다. 행성기어의 축을 묶은 캐리어가 이 공전을 출력축으로 전달한다.

```text
Ns(ωs − ωc) + Nr(ωr − ωc) = 0
링 고정: ωr = 0
16ωs = (16 + 48)ωc
ωc = ωs / 4
i = ω입력 / ω출력 = 1 + 48/16 = 4
```

태양기어 4회전에 캐리어는 같은 방향으로 1회전한다. 행성기어의 절대 자전은 태양기어의 -1/2, 캐리어에 대한 상대 자전은 -3/4이다. 캐리어의 이동과 행성기어의 자전을 각각 적용해야 한다. 행성기어 네 개라는 수량을 감속비의 곱셈 인자로 쓰지 않는다.

이상적 출력 토크는 입력의 4배이며, 효율 η를 반영하면 `T출력 = 4ηT입력`이다. 실제 효율·하중·토크는 측정하지 않았다.

기술 원리 확인 자료:

- [Oriental Motor: Planetary gearhead 구조와 캐리어 출력](https://www.orientalmotor.com/stepper-motors/technology/stepper-motor-gearheads.html)
- [KG STOCK GEARS 기술자료: 고정 부품·입출력에 따른 유성기어비](https://www.kggear.co.jp/en/wp-content/themes/bizvektor-global-edition/pdf/TechnicalData_KGSTOCKGEARS.pdf)

## CAD와 애니메이션

- `커버와 베어링이 제거된 감속기.stl`의 원본 80,230면을 좌표·초기 치형 위상을 유지하며 12개 역할 묶음으로 분리했다. 태양·캐리어·하우징·기타 고정부·행성 4개·행성 지지부 4개다.
- 역할 분류는 메쉬 섬의 치수·반경·축 위치를 기준으로 하며, 정면·사선 참고 영상과 사용자 설명을 대조했다. CAD의 원래 부품 이름을 복구한 것은 아니다. 원본 파일 해시와 역할별 면 수는 `planetary_inventory.json`에 기록한다.
- 실제 CAD의 태양기어는 황금색, 행성기어는 녹색, 캐리어는 청색, 고정 링·하우징은 회색으로 구분한다. 가려진 기어를 읽을 수 있도록 지지부와 캐리어는 투명하게 표시한다.
- 밝은 표시점으로 자전, 점선 원으로 공전 경로, 청색 연결선으로 캐리어의 연결을 설명한다. 이 표시들은 원본 CAD 부품이 아닌 설명용 오버레이다.
- `planetary_rig.js`에서 캐리어와 행성기어의 상대 회전을 분리한다. 화면 계기는 같은 애니메이션 각도에서 계산하고, 51초에 입력 4.00회전·출력 1.00회전에 도달해 감속비 설명 동안 유지한다.
- 분해도에서는 기어 전달을 멈추고 축 방향으로 부품을 띄운다. 치합이 분리된 상태를 실제 구동 상태로 설명하지 않는다.

## 카메라와 설명 구성

전체 CG는 **135초**를 유지하고 12장면에서 **15장면**으로 재구성했다. 감속기 설명은 10초에서 **30초(27–57초)**로 확장했다.

| 시간 | 감속기 설명 | 구도 |
|---|---|---|
| 27–34초 | 태양·행성·링·캐리어 역할 | 고정 사선 분해도 |
| 34–43초 | 자전·공전의 분리 | 축 정면 고정 |
| 43–51초 | 같은 시간의 입력·출력 비교 | 같은 정면 고정, 계기와 회전수 |
| 51–57초 | 16/16/48과 4:1 감속식 | 출력축이 보이는 사선 구도 |

기존의 장면마다 유사하게 도는 카메라와 후진 줌을 없앴다. 도입부의 크레인, 시스템·레일의 횡이동, 단면의 고정 관찰, 감속기의 분해 사선·정면, A/B의 같은 고정 시점, 선회의 상부 시점, 기울임의 낮은 측면, 복합 입력의 짧은 사선 이동을 구분했다. 시스템·동력 전달·십자 조인트·선별 순서에는 단계별 보조 패널을 추가했다.

최신 대본은 `output/ard-cg/CG_개인TTS대본_v3.txt`다. 기존 v2 대본과 초기 3분 기획은 이전 타임라인의 기록이다.

## 검증과 범위

- Python 소스 구문·JavaScript 구문·변경 파일 공백 검사 통과.
- `node output/ard-cg/verify_planetary.cjs`: 실제 원본과 파생 STL의 면 다중집합 일치, 부품 중립 좌표 보존, 10개 운동 사례의 외접·내접 기어 운동식, 고정 링, 행성 중심 궤도, 입력 4회전·출력 1회전 확인.
- 같은 검사에서 135초에 걸친 **541개 시간 표본**의 카메라·자세 수치와 장면 경계 확인. 고정 시점의 유지, A/B 동일 시점, 선회와 기울임의 다른 시점 확인. 이는 GPU 렌더링 프레임 541개를 검사했다는 뜻이 아니다.
- `node output/ard-cg/verify_differential.cjs`: 기존 십자 조인트 분리 회귀 검사 통과.
- 브라우저에서 **15개 장면의 대표 시점**을 직접 열어 구도·문자·기구 자세를 확인했다. 신규 브라우저 실행 오류는 없었다. 기존 Three.js UMD 폐기 예정 경고는 있다.
- 로컬 검수 화면은 `preview_reduction_*.png`, `preview_editorial_*.png`이며 기존 정책에 따라 Git에서 제외한다. 새 환경에서 메쉬를 생성하고 브라우저로 재현할 수 있다.
- 앱·펌웨어·C/C++ 빌드, 135초 모든 프레임 검수, 음성 합성·동기화, 최종 MP4, 실제 치합·백래시·탈조·토크·실물 구동 검증은 하지 않았다.
- 병행 작업의 펌웨어·PC·회로도·PDF 변경은 수정하거나 되돌리지 않았다. 원본 CAD·참고 영상은 보존했다.

## 실행과 미리보기

```powershell
python output/ard-cg/prepare_cad.py
node output/ard-cg/verify_planetary.cjs
node output/ard-cg/verify_differential.cjs
python output/ard-cg/serve.py
```

모두 소스 컴파일 없이 실행한다. 메쉬 처리의 기본 의존성은 NumPy이며, 분석용 임시 스크립트의 OpenCV·SciPy는 미리보기 실행에 필요하지 않다.

- 설명 시작: `http://127.0.0.1:5187/cinematic.html?t=27&still=1`
- 자전·공전: `http://127.0.0.1:5187/cinematic.html?t=38&still=1`
- 4:1 확인: `http://127.0.0.1:5187/cinematic.html?t=54&still=1`
