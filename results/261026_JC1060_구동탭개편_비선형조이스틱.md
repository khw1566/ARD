# JC1060 구동 탭 개편과 비선형 조이스틱

작성일: 2026-10-26

## 화면 구성

1024×600 화면의 고정 상태바·탭 버튼을 유지한다. 구동 탭의 1000×448px 내부에 왼쪽 패널 564px,
간격 12px, 오른쪽 패널 424px를 배치한다. 화면 스크롤과 밀어서 탭 전환은 계속 차단한다.

```text
┌──────────────────────────────┬─────────────────────┐
│ 연결 상태         모드 전환  │ 디스크 / 회전       │
│ 조작 가능 여부               │                     │
│ X/Y/Z · 환경 · ToF · GPS     │     큰 조이스틱     │
│                              │       360px         │
│ 활성화 / 비활성화 / PID / 원점│   중앙 데드존 표시  │
│                              │                     │
│ 레일 누름 조작  간격·데드존   │ 조작 세기           │
└──────────────────────────────┴─────────────────────┘
```

조이스틱 지름을 208px에서 360px로 확대했다. 면적은 약 3배다. 오른쪽에서 조작하고 왼쪽에서
장치 상태와 설정을 확인한다. 연속 모드로 시작하지만, 이동은 기존처럼 Enable과 RE-ARM 후에만 가능하다.
단일 스텝 모드로 바꾸면 오른쪽은 방향별 이동 버튼, 왼쪽 아래는 단위 스텝 설정으로 바뀐다.

## 데드존과 속도 곡선

데드존은 조이스틱 중심에서 움직임을 무시하는 원형 범위다. 기본 반경 20%, 슬라이더 범위 5~30%다.
손잡이 중심의 최대 이동 거리를 100%로 본다. 중앙 원과 설정값, 조작 세기를 함께 표시한다.

정규화한 중심 거리 `r`, 데드존 반경 `d`에 대해 다음 명령 빈도를 사용한다.

```text
r <= d: 0
r > d : ((min(r, 1) - d) / (1 - d))²
```

| 중심 거리 | 기본 데드존에서 최대 명령 빈도 대비 비율 |
|---|---:|
| 0~20% | 0% |
| 40% | 6.25% |
| 60% | 25% |
| 80% | 56.25% |
| 100% | 100% |

PC의 새 `joystick` 동작에서 원형 데드존과 제곱 곡선을 적용한 뒤 전진·회전을 두 디스크 축에 혼합한다.
같은 반경에서는 조작 각도에 관계없이 가장 빠른 축의 명령 빈도가 같다. 축별 간격은
`기본 간격 / 축별 비율`이다. 연속 이동량은 기존처럼 축별 고정 ±20스텝이며 모터 펌웨어의 속도 설정을 바꾸지 않는다.

기본 간격은 슬라이더로 100~640ms, 초기값은 310ms다. 데드존 바로 밖에서는 간격이 길 수 있다.
현재 입력 좌표와 마지막 수락 시각으로 대기를 다시 계산하므로, 조이스틱을 더 기울이면 이전의 긴 간격이 남지 않는다.
화면의 조작 세기는 입력에 따른 요청 빈도이며 실제 측정 모터 속도가 아니다.

기존 `input/pulse` 요청은 동작을 유지한다. 새 제어에는 기존 축별 0.12 데드존을 중복 적용하지 않는다.
중립·손 떼기·250ms 입력 중단·탭/모드 전환에 따른 취소, 명령 300ms 만료, 한 묶음만 대기,
PID·자동 선별·보드 재시작 확인, E-STOP 동작을 유지했다.

## 정량 제어

- 단위 이동량: 1~2000스텝, 기본 50스텝.
- `-1/+1` 버튼과 길게 누르기 반복으로 1스텝씩 조절한다.
- 빠른 선택: 1 / 10 / 50 / 100 / 500 / 1000 / 2000.
- 디스크 전후·회전, X·Y 이동, PID를 끈 레일 이동에 같은 단위가 적용된다.
- PID 레일은 기존 145~175mm 목표를 5mm씩 조절한다. 모터 보정값과 DriveMCU 펌웨어는 변경하지 않는다.
- 이 조작 설정은 재부팅 시 기본값으로 시작한다.

## 검증과 적용

ESP-IDF 5.5.5 / LVGL 9.2.2 메타데이터와 사용 API 선언을 확인했다.
Python 검사에서는 실제 PC 처리 경로의 데드존·제곱 곡선·전후/회전 혼합·좌표 변화에 따른 대기 재계산·중립 취소·만료·보드 상태 제한을 확인한다.
전체 Python 회귀 검사는 **122개 통과**했다(8.994초). 기존 TCP 테스트의 10ms 만료 제한과 관련된 실패가 한 번 있었으며, 해당 코드·테스트를 수정하지 않고 재실행해 통과했다.
번역표는 254개 키, 소스와 불일치 0개다. 한글 글꼴 소스도 갱신했다(275자 × 3크기, 비트맵 232,858 bytes).
이번 작업에서는 빌드·링크·업로드·새 화면 렌더링·실물 동작 시험을 수행하지 않았다.
디스플레이 전송 코드와 패널 초기화 설정도 변경하지 않았다.

PC 프로그램을 다시 시작한 뒤, 사용자가 저장소 루트에서 직접 빌드한다.

```powershell
.\ARD_ESP-IDF\JC1060P470C\build.ps1 build -BuildDirectory build/wifi_debug
```

빌드 성공 후 해당 보드 포트에 업로드한다. 실물에서는 큰 조이스틱의 중앙 중립·끝 위치·방향 혼합,
모드 전환 후 재가동, 레일 누름/해제, 단위 스텝별 이동량을 확인해야 한다.
