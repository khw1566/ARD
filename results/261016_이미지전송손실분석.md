# 이미지 전송 데이터 손실 원인 분석 및 프로토콜 v2
## 1. 결론
데이터 손실의 주원인은 커스텀 패킷 프로토콜이 맞다. 기존 형식은 패킷 앞에 0/1/2(시작/중간/끝) 1바이트만 붙였기 때문에 PC가 청크 누락·중복·순서 뒤바뀜을 알 수 없었고, 손실이 생기면 그대로 이어 붙인 깨진 JPEG를 정상 프레임으로 분석에 넘겼다. 송신 측에는 실패한 청크를 건너뛰고 계속 보내는 버그도 있었다.

## 3. 프로토콜 v2 설계
- 헤더(20바이트, 리틀엔디언): magic `AI`, 버전 2, 타입(DATA/POLL/STATUS), frame_id, chunk_idx, chunk_count, payload_len, total_len, 프레임 CRC32
- 청크 1400바이트 고정. 헤더 포함 UDP 1420바이트, IP 포함 1448바이트로 MTU 1500 이내. 최대 2048청크(약 2.8MB)
- 무결성: UDP 체크섬이 패킷 단위를, 프레임 CRC32(zlib 호환)가 재조립 결과 전체를 검증
- 신뢰성: ESP32가 32청크를 보낸 뒤 POLL, PC가 수신 비트맵을 담은 STATUS로 응답, ESP32는 빠진 청크만 재전송(선택적 재전송). 완성 후 CRC가 맞으면 PC가 COMPLETE를 먼저 보냄
- 흐름제어: 응답 없이 보낼 수 있는 양을 32청크(약 45KB)로 제한. ESP32 TX 큐가 가득 차면(ENOMEM) 같은 청크를 대기 후 다시 보내며 절대 건너뛰지 않음
- 중복·지연 패킷: PC는 최근 완료 프레임 16개를 (frame_id, 크기, CRC)로 기억해 늦게 온 중복을 무시하고 POLL에는 COMPLETE를 다시 답함
- 실패 처리: STATUS가 8번 연속 오지 않거나 시간 제한(3초 + 100KB당 1초)을 넘으면 실패로 기록하고 PC 로그에 이유를 남김
- 하위 호환: 첫 2바이트가 `AI`가 아니면 구형 형식으로 처리. 단 JPEG 시작·끝 마커가 없는 프레임은 폐기

## 4. 구현 위치
- 펌웨어: `ARD_ESP-IDF/ImageSenderMCU` (ESP-IDF 5.5.5, 모듈 인덱스는 README.md)
- PC: `ARD_MAIN` (pc_center 복사본, build·dist·MusicData 제외)
- `ARD_MAIN/backend/network/image_protocol.py`: 소켓과 분리된 수신 상태 머신
- `ARD_MAIN/backend/app.py`: `udp_receive_thread`를 새 수신기로 교체, `SO_REUSEADDR` 제거, 수신 버퍼 4MB, `trigger_image_capture()` 추가(TCP 5003 우선, 실패 시 폴링)
- `ARD_MAIN/tests/test_image_protocol.py`: 펌웨어 송신 알고리즘을 그대로 옮긴 시뮬레이터로 수신기 검증

## 5. 함께 개선한 점
- 촬영 즉시성: TCP 5003 명령 서버 복구, PC는 한 요청당 한 경로만 사용해 중복 촬영 방지
- 새 프레임 보장: 촬영 전 오래된 버퍼 1장 폐기
- 무선 절전 끔(`WIFI_PS_NONE`), Wi-Fi TX 버퍼 16개에서 32개로 늘려 32청크 창과 맞춤, PSRAM에 Wi-Fi 버퍼 할당 허용
- 카메라 소유를 촬영 작업 하나로 통일. 설정 변경은 촬영 작업이 적용하므로 HTTP 처리 중 카메라 재초기화 충돌이 없음
- 하트비트 30초에서 10초로 단축 (PC 오프라인 판정 30초보다 짧게)
- 브라운아웃 보호는 SDK 기본값 유지, CPU 160MHz 유지 (261003 보고서 결과 반영)

## 6. 검증 결과
- 손실 시뮬레이션 8개 테스트 통과: 손실 없음, 경계 크기(1, 1400, 1401바이트 등), 15% 손실+5% 중복+10% 순서 뒤바뀜에서 250KB 프레임 20회, CRC 오류 후 전체 재전송, 연속 10프레임, 잘못된 헤더 거부, 실제 UDP 소켓 왕복
- 같은 조건에서 구형 형식은 중간 청크가 빠져도 프레임을 정상으로 넘김을 테스트로 재현
- 기존 선별 파이프라인 테스트 12개 통과
- `idf.py build` 성공 (ESP-IDF v5.5.5, esp32s3). 앱 크기 0x112520바이트, 앱 파티션 여유 27%. 경고 0건
