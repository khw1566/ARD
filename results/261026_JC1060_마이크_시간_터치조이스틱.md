# JC1060 마이크 상태·시간·터치 조이스틱 소스 수정

작성일: 2026-10-26

## 적용 내용

1. **JC1060 터치 화면의 마이크 상태**: 마이크 설정을 바꾼 직후 화면을 갱신한다. 현재 상태 `MIC ON/OFF`, 다음 동작 `Turn mic on/off`, 상태 색을 함께 바꾼다. PC 음성 보드 미선택과 마이크 꺼짐을 별도 상태로 표시한다.
2. **네트워크 연결 후 시간 표시**: IP 획득 시 SNTP를 시작한다. 인터넷 시간 서버에 접근하지 못할 때는 PC의 `/api/hmi/updates`에 추가한 `unix_time`을 받아 보정한다. 유효 범위·숫자 검사를 거치고 2초 이내 차이는 보정하지 않는다. 표시는 한국 시간(UTC+9)이다.
3. **빌드 지침 기록**: 루트 `AGENTS.md`에 에이전트 직접 빌드 금지를 기록했다. 펌웨어·시뮬레이터·C/C++ 호스트 테스트를 포함하며 다른 스크립트나 에이전트를 통한 우회도 금지한다. 소스 수정과 컴파일 없는 해석형 검사는 허용한다.
4. **Drive 제어 UI**: 기존 단일 스텝 버튼을 유지하고 모드 전환을 추가했다. 연속 모드에서 원형 조이스틱은 전후 이동·회전을 합성하고, 별도 레일 버튼은 누르는 동안 이동한다. 게임패드는 다시 추가하지 않았다.

## 연속 제어 방식

- DriveMCU 펌웨어·기존 명령 프로토콜·모터 속도 설정을 변경하지 않는다.
- PC의 새 `pulse` 동작은 축마다 고정 ±20스텝을 보낸다. 기존 `input` 동작의 스텝 계산은 호환성을 위해 유지한다.
- 슬라이더는 기본 명령 간격을 100~640ms로 조절한다. 조이스틱의 축별 기울기가 작을수록 `기본 간격 / 기울기 절댓값`만큼 대기를 늘린다. 0.12 이하는 중립으로 처리한다.
- 각 축의 간격은 실제 명령 수락 응답부터 다시 계산한다. 방향 반전으로 대기 제한을 우회하지 않는다. 실제 반복 속도에는 통신과 이전 이동 완료 대기도 포함된다.
- PC에는 한 묶음만 대기시키고 입력을 쌓지 않는다. 미전송 명령의 유효 시간은 300ms다. 이동 중·PID 켜짐·자동 선별 중·보드 재시작을 확인하면 새 연속 명령을 제한하거나 수동 제어를 해제한다.
- 터치 화면은 50ms마다 눌림 상태를 확인한다. 손을 떼면 중립을 보내고, 입력 갱신이 250ms 중단되면 새 펄스를 중단한다. 탭·모드 전환, 승인 팝업, 통신 문제에서도 수동 제어를 해제한다.
- 수동 제어 해제는 자동 선별을 취소하지 않는다. E-STOP은 구동·자동 선별을 중단하는 기존 역할을 유지한다. 이미 물리 보드가 수락한 유한 이동은 통신 해제로 되돌릴 수 없다.

## 확인 결과와 한계

- PC Python 회귀 테스트: `python -m unittest discover -s ARD_MAIN/tests -p test_*.py` — **112개 통과**.
- 새 검사는 고정 펄스 크기, 축별 간격, 수락 응답 이후 대기, 방향 반전, 중립 취소, 만료된 명령 폐기, 입력 검증, 보드 상태 제한, 자동 선별과 수동 해제 분리, PC 시간 응답을 확인한다.
- 화면 번역 검사: **244개 키, 불일치 0개**.
- 한글 글꼴 소스 갱신: 278자 × 3크기, 비트맵 235,372 bytes. 소스 생성만 수행했다.
- 수정된 빌드 스크립트는 PowerShell 구문 검사만 수행했다. 현재 PC의 ESP-IDF 5.5.5 경로와 C6 전송 선택에 필요한 `ESP_IDF_VERSION=5.5`를 명시하고 기존 `build/wifi_debug` 폴더를 선택할 수 있게 했다.
- **이번 변경에 대해 에이전트는 빌드·링크·업로드·실물 터치 검증을 수행하지 않았다.** 현재 보드에는 이번 소스 변경이 적용되지 않았다.

## 사용자가 적용할 때

수정된 PC 프로그램을 다시 시작하고, 저장소 루트에서 다음 명령을 직접 실행한다.

```powershell
.\ARD_ESP-IDF\JC1060P470C\build.ps1 build -BuildDirectory build/wifi_debug
```

빌드 성공 후 P4 업로드와 모니터를 실행한다. `COM22`는 이전 연결 포트이며 포트가 바뀌면 수정한다.

```powershell
.\ARD_ESP-IDF\JC1060P470C\build.ps1 flash -Port COM22 -BuildDirectory build/wifi_debug
```

Voice 탭에서 마이크 상태·색·다음 동작 문구를 확인하고, 네트워크 연결 후 한국 시간이 표시되는지 확인한다. Drive 탭은 단일 스텝 모드로 시작한다. 연속 모드로 전환한 뒤 Enable과 RE-ARM을 누르고, 조이스틱·레일의 눌림/해제 및 간격 슬라이더 반응을 확인한다. 모드나 탭을 바꾸면 다시 RE-ARM이 필요하다.
