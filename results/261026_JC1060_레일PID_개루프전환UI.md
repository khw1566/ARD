# JC1060 레일 PID·개루프 전환 UI

## 화면과 조작

- 구동 탭 옆에 `레일` 탭을 추가했다. 기존 구동 화면의 PID 버튼은 레일 탭으로 이동하는 `레일 제어` 버튼으로 바꿨다.
- 레일 탭의 스위치로 PID/개루프 제어 방식을 선택한다. 모드 선택은 PC JSON의 `mode`를 저장하며 선별 시퀀스에도 같은 방식을 사용한다. 전환 시 `mzm0` ACK를 확인하지만 PID 이동은 시작하지 않는다.
- PID 모드: 목표 슬라이더, ±1 mm 버튼, 금속·종이/중앙/플라스틱·유리/촬영 위치 프리셋, `목표로 이동` 버튼. 프리셋 선택만으로 움직이지 않는다.
- 프리셋과 조절 범위는 PC 설정에서 읽는다. 현재 값은 70/95/120/120 mm이고 목표 범위는 티칭 범위 ±10 mm다. 이전 145~175 mm 고정 범위를 제거했다.
- 현재 ToF와 오류 상태, 보드 목표, 거리 오차, 실제 PID ON/OFF, 정착 여부, P·I·D 현재값을 표시한다. 계수 편집은 PC의 PID 카드에서 한다.
- 개루프 모드: 단위 스텝 조절과 Z +/- 스텝 이동. ToF는 표시만 하며 ToF 오류가 있어도 개루프 이동은 가능하다. 단위 이동량은 1~2000 steps로 제한한다.
- `레일 정지`는 `mzm0` 뒤 `mzx`를 보내 Z축을 감속 정지한다. 기존 상단 비상정지는 별도로 유지한다.
- HTTP 명령 수락과 실제 정착을 구분한다. 실패·시간 초과를 표시하고 PC가 확인한 모드로 스위치를 갱신한다.
- 한글 번역과 폰트 C 소스를 갱신했다. 폰트 생성은 Pillow로 비트맵 소스만 생성하며 컴파일하지 않는다.

## 통신과 제약

- `/api/hmi/updates`의 `rail`로 PC 설정을 전달한다. `drive`에서 실제 ToF 유효성·PID 계수·이동 상태를 받는다.
- 새 `/api/jc1060/rail`은 선택된 JC1060의 IP에서만 허용한다. 선별 작업 중 조작은 거부한다. 다른 수동 조그가 진행 중이면 먼저 취소하고 정지 확인 후 재시도하도록 한다.
- PID 이동은 티칭 완료, 유효 ToF, 비상정지·조그 해제와 모터 상태를 확인한다. 시작 시 PC에 저장된 방향/Steps/mm/P·I·D를 적용한 뒤 목표와 PID ON을 전달한다.
- 개루프 스텝 명령은 PID 모드에서 거부한다. 기존 구동 탭의 단발 레일 버튼도 같은 경로를 사용하고, PID 방식 선택 중 연속 레일 조그 입력을 막는다.
- 큐에서 500 ms 넘게 기다린 레일 요청은 실행하지 않고 timeout 결과로 보고한다.
