2026-10-26, 한국 시간.

## 요청과 권한

사용자가 `C:\Users\work\Desktop\myTTS`의 학습된 목소리로 현재 CG를 영상화하고 효과음·배경음악을 넣도록 요청했다. 이어서 **“빌드 허용할게”**라고 직접 승인했다. 이번 제작은 해당 최신 지시에 따라 진행했다. 펌웨어 빌드·장치 제어·외부 배포는 수행하지 않았다.

## 출력물

- `output/ard-cg/final/ARD_CG_MyVoice_1080p.mp4`: 1920×1080, 30fps, 135초, H.264/AAC, 4,050프레임.
- `ARD_narration_only.wav`: 나레이션만 있는 48kHz 스테레오 WAV.
- `ARD_final_mix.wav`: 음악·효과음을 포함한 PCM 믹스. MP4에는 추가 라우드니스 마스터링을 반영했다.
- `ARD_Korean_transcript.srt`, `.vtt`: 실제 나레이션의 컷별 대본 자막. 기존 화면 설명 자막도 영상에 포함한다. SRT/VTT는 컷별 음성 시작·종료 기준이며 단어 단위 강제 정렬은 아니다.
- `CREDITS.txt`: 음원 출처, 이용 조건, 편집 내용.
- `video_probe.json`, `audio_manifest.json`, `mastering_levels.json`, `narration_asr_review.json`: 파일·오디오 구성·음성 인식 보조 검수 기록.

이 결과는 현재 제작 중인 **CG 부분 2분 15초**다. 실물 분류 촬영본 45초를 임의로 만들거나 CG를 실물 촬영으로 표시하지 않았다.

## 음성

- 기존 `myTTS/.venv`와 `tts_engine.py`의 `VoiceTTS`를 읽어 사용했다. 원본 모델과 학습 데이터는 수정하지 않았다.
- 기존 학습 체크포인트 `runs/myvoice_xtts-October-17-2026_12+37PM-0000000/best_model.pth`와 기존 참조 음성을 사용했다. 추가 학습과 외부 음성 업로드는 하지 않았다.
- 한국어 15컷을 GPU에서 합성하고, 무음 가장자리 정리·저역/고역 필터·음량 맞춤·필요한 컷의 피치 보존 속도 조정을 적용했다.
- 최신 제작용 대본은 `CG_개인TTS대본_v4.txt`다. 부품 소개에서 TTS가 흐리게 읽는 외래어는 같은 의미의 쉬운 한국어 정의로 설명하고 화면의 정식 부품 명칭과 연결했다. 감속비 수식은 화면으로 보여주고 나레이션에서는 4:1을 명확하게 읽는다.
- 기존에 캐시된 로컬 faster-whisper-small로 컷별 대본을 보조 대조했다. 재합성한 구간도 다시 대조했다. ASR의 영문 약어·숫자 표기 및 전문용어 오인식은 실제 발음 오류와 같다고 단정할 수 없으며, 점수를 발음 정확도나 생체 음성 동일성의 증명으로 사용하지 않는다.

## 영상 출력 방식

- `export.html`/`export_video.js`가 실제 Three.js 장면을 프레임별 정확한 시간으로 그린다. 별도 SVG/HTML 합성으로 화면 제목·수식·계기·지시선·자막·크레딧을 같은 프레임에 넣는다. 플레이어 컨트롤은 제외한다.
- 브라우저 WebCodecs의 H.264 Annex B 인코더를 사용했다. 로컬 전용 `render_server.py`는 127.0.0.1:5188에서 순서가 확인된 청크만 수신한다.
- 4,050프레임 출력과 인코더의 출력 개수가 일치했으며, 원본 프레임 렌더에 약 91.6초가 걸렸다. 이는 **이번 PC의 출력 작업 시간**이며 실시간 재생 FPS나 장치 성능 측정이 아니다.
- FFmpeg/NVENC로 MP4를 인코딩하고 스테레오 AAC 음성·선택형 한국어 대본 자막을 결합했다. 이후 음성 교체는 영상 스트림을 재인코딩하지 않고 반영했다.
- 재생은 `http://127.0.0.1:5187/review.html` 또는 MP4 파일을 사용한다. 로컬 서버를 사용하지 않아도 MP4 자체는 재생 가능하다.

## 재현과 보존

### 최종 확인

- 1920×1080, 30fps, 135.000초, 디코딩 4,050프레임 확인.
- 전체 영상·오디오 디코딩 완료, 0.5초 이상 검은 화면 구간 없음.
- 최종 AAC 포함 파일의 통합 음량 **-16.09 LUFS**, 트루피크 **-1.35 dBTP**, 음량 범위 **4.2 LU**.
- 15개 장면의 대표 시점을 최종 MP4에서 추출하고, `final/contact_sheet.jpg`와 프레임별 검수 이미지로 확인했다. 모든 프레임을 사람이 시각 검수했다는 의미는 아니다.
- 브라우저에서 완성 MP4의 135초·1920×1080 메타데이터, 재생 시작과 진행, 오류 없음 확인.
- 최종 파일 해시·바이트 수는 `final/quality_report.json`이 기준이다. 음성과 전문용어의 발음 평가는 로컬 ASR 보조 대조이며 사람의 청취·생체 음성 동일성 검증을 대신하지 않는다.

1. `myTTS/.venv/Scripts/python.exe output/ard-cg/synthesize_narration.py --script output/ard-cg/CG_개인TTS대본_v4.txt`
2. `python output/ard-cg/mix_audio.py`
3. `python output/ard-cg/render_server.py`, 그 뒤 `/export.html`에서 시험 프레임 확인 후 영상 렌더링.
4. `python output/ard-cg/finalize_video.py`; 음성만 갱신할 때 `--audio-only`.

개인 합성 음성·다운로드 음원·렌더 중간 결과·최종 영상은 `.gitignore`의 전용 경로에 보존했다. 작업 중 병행 변경된 펌웨어·PC·CAD·PDF·회로도는 되돌리거나 커밋하지 않았다.
