# JC1060 스크롤 제거와 카메라 전체 이미지 표시

작성일: 2026-10-26

## 수정 원인

1024×600 화면에서 상태바 72px와 탭 버튼 56px를 제외한 탭 높이는 472px다.
이전 Drive·Cam·Voice 패널은 높이가 470~480px여서 탭 자체의 여백을 더하면 화면 아래로 넘쳤다.
기본 LVGL 컨테이너가 스크롤 가능했고, 조이스틱을 놓는 코드가 탭 영역의 스크롤을 다시 켰다.
카메라는 원본 크기의 이미지 객체에 확대·축소만 적용해 원본 객체의 배치 크기가 남아 있었다.

## 소스 변경

- `main/ui_layout.h`에서 상태바·탭·여백 크기를 통일했다. 일반 탭 내부 크기는 1000×448px다.
- 페이지·패널·조작 버튼의 스크롤, 관성, 탄성, 부모로의 스크롤 전파를 차단했다.
  메인 탭과 설정 하위 탭은 버튼으로 전환한다. LVGL의 탭 버튼이 사용하는 프로그램 내부 위치 전환은 유지한다.
- 조이스틱 해제 시 탭 스크롤을 다시 켜는 코드를 제거했다. 조이스틱·레일·슬라이더의 기존 입력 기능은 유지한다.
- Drive 패널 높이를 448px로 줄이고 상태·환경·GPS·전원 버튼을 고정 위치에 배치했다.
  연속 제어와 단일 스텝 패널을 동일한 높이에 맞췄다. Voice·System 패널도 448px 안에 배치했다.
- 카메라 왼쪽에는 상태·메타데이터·촬영/보기/분석/스트림 버튼을 배치했다.
  오른쪽에는 616×392px 이미지 표시 영역과 별도 상태 줄을 뒀다.
  원본 이미지의 비율로 목적 크기를 계산하고, 이미지 객체 자체도 그 크기로 설정한다.
  가로·세로·정사각 이미지 모두 표시 영역 안에 들어가며 남는 부분은 배경 여백으로 둔다.
- 설치된 LVGL 9.2.2에는 `CONTAIN` 정렬이 없으므로 존재하는 `LV_IMAGE_ALIGN_STRETCH`를 사용한다.
  먼저 비율을 유지한 목적 크기를 결정해 왜곡을 최소화한다. 정수 픽셀·배율 단위에 따른 반올림은 남는다.
  이 버전은 소스를 지정할 때 배율을 계산하므로 목적 크기의 배치 갱신을 먼저 수행한다.
- 설정의 Wi-Fi 결과는 4개와 이전·다음 버튼으로 표시한다. 최대 20개 결과를 스크롤 없이 선택할 수 있다.
  설정 입력칸은 화면을 밀지 않고 긴 입력만 가로로 이동한다. 화면 키보드는 기존처럼 입력 중에만 열린다.
- 메인 탭의 패널 제목과 배출함 설명은 패널 폭에 맞춰 줄바꿈한다.

## 확인 범위

에이전트 빌드 금지 지침을 유지했다. ESP-IDF 5.5.5 / LVGL 9.2.2의 로컬 선언과 구현을 확인했다.
preflight는 메타데이터만 읽었으며 컴파일을 실행하지 않았다. 번역 검사와 변경 공백 검사를 수행했다.
펌웨어 빌드·업로드·새 화면 렌더링·실물 터치 검증은 수행하지 않았다.

## 적용 후 확인

사용자가 새 소스를 빌드·업로드한 뒤 각 탭의 하단 버튼과 정보를 확인한다.
카메라에서 가로/세로 이미지의 가장자리가 모두 표시되는지, 새 촬영과 스트림에서도 영역이 움직이지 않는지 확인한다.
조이스틱을 화면 가장자리까지 움직였다 놓아도 페이지가 밀리지 않고, 손을 뗀 뒤 새 연속 명령이 중단되는지 확인한다.
탭 전환은 상단 버튼을 사용한다. 설정의 Wi-Fi 검색 결과는 이전·다음 버튼으로 선택한다.

저장소 루트에서 사용자가 실행할 빌드 명령:

```powershell
.\ARD_ESP-IDF\JC1060P470C\build.ps1 build -BuildDirectory build/wifi_debug
```
