# SoftAP / Wi-Fi / mDNS 적용 결과
운영용 펌웨어 6개에 설정 AP, Wi-Fi 접속 정보 저장, 자동 재접속, 고유 mDNS 호스트 이름과 설정 웹 페이지를 적용했습니다.

## 사용 방법
- [공통 설정 안내](../shared/ArdNetwork/README.md)를 참고하세요.
- 보드 AP: `ard-control-xxxxxx`, `ard-drive-xxxxxx`, `ard-hmi-xxxxxx`, `ard-image-xxxxxx`, `ard-robot-xxxxxx`, `ard-image-p4-xxxxxx`.
- `xxxxxx`는 MAC 끝 3바이트의 소문자 16진수입니다. AP 비밀번호는 `ARD-xxxxxx!`, 웹 로그인은 `admin` / AP 비밀번호입니다.
- `http://192.168.4.1/network` 또는 `http://보드AP이름.local/network`에서 Wi-Fi 이름·비밀번호와 PC 주소를 입력합니다.
- 저장하면 재부팅합니다. 장치를 정지한 상태에서 설정하세요.
- 저장된 네트워크에 DHCP로 연결하고 실패·끊김 시 15초마다 재시도합니다. AP는 계속 유지합니다.
- PC 주소는 IPv4·DNS·mDNS `.local`을 지원하며 `.local` 주소는 30초마다 갱신합니다. PC가 해당 이름을 광고해야 합니다.

## 검증
- 각 대상의 컴파일·링크·BIN 생성과 앱 파티션 크기 검사 통과.
- 공통 설정 헤더의 NVS 버전/손상 검증, SSID 바이트 길이, 공개 Wi-Fi·WPA 비밀번호·64자리 PSK, 잘못된 서버 주소 검증 통과.
- P4 폼 디코더의 한글 UTF-8, 특수문자, 중복 필드, NUL, 잘못된 URL escape, 경계 길이 테스트 통과.
- Drive 기존 native 회귀 테스트 통과: 명령 길이·센서 장애·시간 오버플로·STOP/재개·비상정지.
- P4·C6 배포용 flash_args의 참조 파일 존재·크기·주소 비중첩 확인. C6 OTA 초기 데이터 포함.
- 로그는 프로젝트 루트 `tmp/network-*-build.log`, `tmp/network-drive-regression.log`에 보관했습니다.

## P4 / C6
- [P4 안내](../ImageSenderMCU_P4/README.md).
- P4의 GPIO18/19/14/15/16/17 SDIO와 GPIO54 리셋을 사용해 내부 C6와 연결합니다.
- P4 앱 파티션을 기존 1MB에서 1500KB로 확장했습니다. 기존 앱만 덮어쓰지 말고 부트로더·파티션·앱을 함께 업로드하세요.
- `build_p4.ps1`과 `build_c6.ps1`로 각각 생성합니다. P4는 기존 USB, C6는 C6 UART 업로드 포트를 사용합니다.
- P4는 Ethernet을 우선하며 Wi-Fi 연결이 있으면 Ethernet 해제 시 Wi-Fi를 사용합니다.
- P4의 카메라 미리보기 `/`와 `:81/stream`, JPEG 촬영/전송 프로토콜을 유지합니다.
- P4의 heartbeat RSSI는 현재 0 고정입니다.

## 코드 인덱스와 변경 범위
- [공통 모듈과 코드 인덱스](../shared/ArdNetwork/README.md#코드-인덱스).
- 각 운영 MCU의 `src/main.cpp`, `platformio.ini`에서 공통 모듈을 사용합니다.
- P4: `main/ard_network.c`, `main/ard_network_http.c`, 공통 HTML/검증 헤더, `main/main.c`, `main/ard_sender.c`, CMake/의존성/SDIO 설정 및 빌드·업로드 스크립트.
- 기존 Wi-Fi 후보/비밀번호 하드코딩을 제거했고 저장된 유효한 구형 설정은 읽어 사용합니다.
- PC backend 프로토콜, 모터 제어, 카메라 핀과 센서 처리 설정은 유지했습니다. 설정 메뉴의 Bluetooth/시리얼 무한 대기를 웹 설정으로 대체했습니다.
- OldVersions, D2/TEST, 외부 라이브러리 예제와 Wi-Fi 비활성 전원 진단 펌웨어는 제외했습니다.

## 실물 검증 경계
보드 업로드, SoftAP 접속, 공유기 연결, mDNS 응답, Ethernet/Wi-Fi 전환, 실제 영상 수신과 장시간 안정성은 수행하지 않았습니다.
C6에는 ESP-Hosted 2.12.2 호환 보조 펌웨어가 필요합니다. 다른 C6 펌웨어가 있으면 별도 업로드가 필요합니다.
