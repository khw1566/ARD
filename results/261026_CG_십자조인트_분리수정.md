# CG 중앙 십자 조인트 분리 수정

2026-10-26, 한국 시간.

## 증상과 원인

사용자가 차동 베벨구조 설명에서 십자 조인트가 별개 요소가 아니어서 출력부와 통으로 움직인다고 제보했다. 기존 `prepare_cad.py`는 연결된 메쉬 섬의 경계 위치로 역할을 추정했고, 중앙 십자 조인트를 `output`으로 분류했다. `cinematic.js`가 이 묶음에 기울임과 선회를 함께 적용해 십자 조인트까지 출력축 주위로 선회했다.

## 변경

- 사용자가 수동으로 가져온 중앙 십자 조인트·상단부·하단부 STL을 기존 `베벨기어 조립체.stl`의 면과 정확히 비교해 분리했다. 원본 파일은 수정하지 않는다.
- 분리 결과: A 21,904면, B 21,904면, 십자 조인트 4,646면, 상단부 21,102면, 하단부 21,102면. 총 90,658면이며 원본 조립체와 누락·중복 없이 일치한다.
- 별도 A/B STL은 원본 조립체와 치형의 초기 위상이 달라 사용하지 않는다. 조립체에서 상단부·하단부·십자 조인트를 제외한 면으로 A/B를 얻는다.
- 공통 `differential_rig.js`에서 캐리어에 기울임만 적용하고, 상·하 기어가 캐리어의 로컬 출력축 주위에서 각각 선회하도록 계층을 나눴다. 플레이트는 상부 출력에 연결한다. 전체 장치와 확대 장면에 같은 리그를 사용한다.

```text
root (기존 공통 축 교차점)
├─ A: Rx(a)
├─ B: Rx(-b)
└─ carrier: Rx(φ)
   ├─ cross: 추가 선회 없음
   ├─ output: Ry(ψ)
   │  └─ plate
   └─ bottom: Ry(-ψ)

ψ = (a+b)/2, φ = (a-b)/2
```

- 십자 조인트에 구별 가능한 재질을 적용했다. 44초 장면의 설명과 개인 TTS 대본 C05에도 조인트와 출력축의 다른 역할을 반영했다.

## 확인한 범위

- STL 21개의 바이너리 크기·유한 좌표 검사 및 미리보기 메쉬 생성 완료.
- `node output/ard-cg/verify_differential.cjs` 통과. 실제 생성 STL을 읽어 면 분할, 계층, 공통 피벗, 중립·A 단독·B 단독·같은 입력·반대 입력·복합 입력·음의 입력·중립 복귀의 8개 자세 행렬을 확인했다.
- 기울임을 유지하고 선회만 바꿔도 십자 조인트의 전체 변환 행렬이 그대로 유지되는 회귀 조건을 확인했다.
- Python 소스 구문, JavaScript 구문 및 변경 파일의 `git diff --check` 통과.
- 로컬 브라우저의 같은 입력(87초), 반대 입력(101초), A 단독(59초), B 단독(73초), 복합 입력(113초) 장면을 직접 확인하고 `output/ard-cg/preview_cross_*.png`에 화면을 기록했다. 이 이미지들은 기존 정책에 따라 Git에서 제외한다. 실행 오류 로그는 없었으며, 기존 Three.js UMD 스크립트의 폐기 예정 경고는 있다.
- 앱·펌웨어·C/C++ 빌드와 실물 구동 검증은 하지 않았다. 실제 감속비·베벨기어비·축 부호, 접촉·백래시·하중·탈조는 미검증이다. 최종 영상 승인·개인 TTS 동기화·MP4 인코딩도 하지 않았다.

## Git 및 원본 보존

- `jc1060-wifi-korean-camera`에서 인수인계가 지정한 `ard-v1`으로 전환하고 `origin/ard-v1`의 `b546798`까지 fast-forward 풀했다. 원격 대비 커밋 수는 `0 0`이다.
- 기존 DriveMCU와 PC 설정 파일 수정은 백업 후 stash로 보존하고 풀 이후 충돌 없이 적용했다. stash도 남겨 두었다.
- 수동으로 가져온 CAD 폴더의 파일 30개를 백업하고 SHA-256으로 복원을 확인했다. 원격에 없는 STL 4개와 원격본과 다른 감속기 STL 1개를 포함해 사용자가 가져온 버전을 보존했다.
- 백업: `tmp/pull-backups/20261026-174813/`. `tmp/`는 기존 Git 제외 대상이다. 로컬 비공개 파일을 커밋하거나 외부 배포하지 않았다.

## 미리보기

```powershell
python output/ard-cg/prepare_cad.py
python output/ard-cg/serve.py
```

- 같은 입력: `http://127.0.0.1:5187/cinematic.html?t=87&still=1`
- 반대 입력: `http://127.0.0.1:5187/cinematic.html?t=101&still=1`
- A 단독: `http://127.0.0.1:5187/cinematic.html?t=59&still=1`

두 Python 명령은 소스 컴파일을 하지 않는다. NumPy가 없으면 인수인계의 사전 빌드된 패키지 설치 절차를 따른다.
