# JC1060 화면 보호기 픽토그램 애니메이션 개편

- 대상: `ARD_ESP-IDF/JC1060P470C/main/ui_screensaver.cpp` (헤더·호출부 변경 없음). 이전 버전 백업: `output/screensaver_backup/ui_screensaver.cpp.20261026_before_pictogram`.
- 문구 위주 화면을 4개 픽토그램 장면으로 교체. 장면마다 손 모양 아이콘이 직접 누르고 터치 지점에 물결 원 표시.
  1. 로봇 체험: 터치 화면 아이콘을 손가락으로 터치 → 화면 켜짐 → 탭 선택.
  2. 조이스틱: 재가동 버튼 누름(회색→초록) → 조이스틱을 오른쪽/왼쪽으로 누르는 동안 갠트리 캐리지 이동(방향 화살표 깜빡임) → 손을 떼면 손잡이 복귀·정지.
  3. 선별: 1-2-3 순서 표시, 부품이 컨베이어로 이동 → 카메라 촬영(빔·렌즈 플래시) → 체크 표시 → 분류함으로 투입.
  4. 안전: 움직이는 갠트리 + 경고 삼각형, 다가가는 손에 금지 표시 → 비상정지 버튼 누름 → 캐리지 정지.
- 공통: 상단 실제 비상정지 버튼을 가리키는 빨간 화살표(위아래로 움직임), 제목·설명 1줄, 페이지 점·진행 표시줄, 하단 "도움말 애니메이션" 안내 유지.
- 슬라이드 7초·음성 안내 연동·터치 후 손 떼면 복귀·승인/알림 우선 동작은 그대로.
- 부드러운 움직임을 위해 화면 보호기 전용 33 ms LVGL 타이머 추가(표시 중에만 동작, 숨기면 일시정지). 기존 250 ms refresh에서는 애니메이션하지 않음.
- 모두 LVGL 기본 도형(lv_obj 둥근 사각형/원, lv_line)으로 구성, 비트맵 없음. 값이 바뀐 객체만 갱신.
- 새 문구 없음(글꼴 재생성 불필요). 쓰지 않게 된 번역 3개 삭제: "You can take part!", "Touch anywhere below to enter control mode", "E-STOP remains available at the top of the screen.".
