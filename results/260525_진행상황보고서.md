# [추가 업데이트 내역 - 2026-05-25 오후] 
- **조이스틱 오프라인 시뮬레이션 적용**: 로봇 MCU가 꺼져있어도 PC의 3D 대시보드 시뮬레이션에서는 조작 상태(연속 이동 포함)가 즉각 반영되도록 `app.py` 수정 완료
- **유튜브 음악 영구 보관 및 플레이어 통합**: `yt-dlp`의 플레이리스트 전체 다운로드 버그를 막고 (`noplaylist: True`), 임시 폴더 대신 `MusicData/Youtube/` 폴더에 원곡 제목(.wav)으로 음원을 영구 저장. 임시 재생 방식에서 정식 `MusicPlayer`를 통한 재생으로 통합하여 완벽한 오프라인 라이브러리 및 탐색 제어 지원 구현
- **Music Library UI 분리**: PC Center의 `main.js`를 전면 수정하여, 사용자가 직접 넣은 '수동 추가 음악'과 '유튜브 다운로드 음악'을 각각의 아이콘 및 카테고리로 분리하여 시각화 완료
- **실시간 라디오 시스템 개편 및 유튜브 라이브(Live) 해독 기능 추가**: 공중파 방송국들의 M3U8 차단 문제를 해결하고자 기존 `RADIO_STATIONS` 목록을 안정적인 URL들로 전면 교체. 또한 라디오 주소에 유튜브 링크 입력 시 자동으로 백그라운드에서 라이브 스트림 원본을 해독하여 고품질 라디오로 재생하는 획기적인 기능 추가
- **사운드 패킷(UDP) 충돌(Collision) 해결**: 유튜브 음악 재생이나 PC 가로채기(Audio Mirror) 스트리밍 중, AI 음성 안내(TTS)나 HMI 팝업 소리가 송출되면 동일한 포트로 패킷이 동시 발송되어 오디오가 깨지는 현상 수정. `VoiceQueueManager`에서 이벤트 발생 시 실시간으로 배경 음악 및 PC 사운드 스트리밍을 강제 일시 정지(Pause)하고 안내가 끝나면 자동 재개되도록 완벽한 큐 제어 로직 완성
- **AI 음성 명령 모호성 해결 (사용자 선택지 제공)**: 사용자가 "음악 틀어줘" 혹은 "모터 움직여줘" 같이 모호하게 명령할 때, AI가 자체 판단하여 잘못 동작하는 문제를 방지. 유튜브 검색 리스트(`search_youtube_list`) 도구를 추가하여 AI가 5개의 검색 결과를 챗 화면에 보여주고 사용자에게 선택을 요구하며, 모터 제어 시에도 명확한 제어 대상을 묻도록 페르소나 및 시스템 프롬프트(System Instruction) 강화.
- **유튜브 다운로드 진행률 채팅 UI 시각화**: `yt-dlp`의 `progress_hooks`를 SSE 스트림에 연결(`youtube_progress` 이벤트). 유튜브 음원을 다운로드할 때 멈춘 것처럼 보이는 현상을 방지하기 위해, 웹 UI 채팅방 하단에 실시간 다운로드 퍼센테이지(%)를 시각적 버블 애니메이션으로 띄워 진행 상황을 직관적으로 확인 가능하도록 수정 완료.
