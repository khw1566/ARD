## 충돌 해결

`ard_network.c`, `ard_network_http.c`, `ui.cpp`의 겹친 내용을 해결했다.

- Setup QR는 System 탭에 유지하고, 밝기는 Settings → Display로 통합했다.
- 웹 설정의 검색·기록 기능과 터치 설정의 실시간 연결 기능을 모두 유지했다.
- 공통 코드와 터치 UI가 서로 다른 `ard_wifi_ap_t` 구조를 정의하던 충돌을 제거했다. 터치 전용 구조는 `ard_network_ap_t`다.
- JC1060의 자동 연결·웹 검색·터치 검색/연결을 같은 작업 게이트로 직렬화했다.
- 터치 연결 전에 공통 작업 코드의 활성 프로필을 갱신하여, 새 연결 성공을 이전 SSID의 성공으로 잘못 기록하지 않도록 했다.
- 수동 연결 실패 시 실제로 활성화됐던 이전 프로필로 복구를 시도한다. 자동 기록 선택은 기존처럼 검색에 보이는 SSID만 사용하고, 터치의 직접 입력은 숨김 SSID도 시도할 수 있다.
- 새 체크아웃에서도 정상 동작 설정을 재현하도록 V2 + 전체 화면 동기 갱신을 기본 설정에 반영했다. 기존 `sdkconfig`의 명시적 선택은 변경하지 않았다.
