# ARD 외부 웹 접속 구축

작성일: 2026-10-22 (KST)

작성자: Codex

- 접속 주소: https://ard.audreaming.com
- 기존 `audreaming.com`의 Cloudflare Worker 홈페이지 연결은 보존함.
- Cloudflare 전용 터널 `ard-main-program` 생성 및 새 하위 도메인 DNS 연결 완료.
- 비밀번호 로그인 게이트웨이를 로컬 포트 5006에 설치. 메인 서버는 기존 포트 5000 사용.
- Cloudflare Tunnel에서 공개하는 대상은 비밀번호 게이트웨이 하나로 제한함.
- 비밀번호는 `.remote-access/connection.txt`에 저장. 인증 파일·세션 키·로그·비밀번호 파일은 Git 제외.
- 비밀번호 변경·로그아웃·로그인 실패 제한·요청 출처 검사 적용.
- 기존 서버와 현재 화면 간 ControlMCU 음성 설정 이름 및 API 경로 차이를 수정함.
- 소스의 기본 API 키를 제거하고 로컬 `.env` 설정으로 이동함. 과거 Git 커밋의 내용을 수정하거나 키를 폐기한 작업은 아님.
- Windows 실행용 Waitress 3.0.2를 기존 Python 3.12 환경에 설치하고 운영용 서버로 기동함.
- `start_remote.bat`, `stop_remote.ps1`, `change_remote_password.bat` 제공.
- Windows 시작 시 자동 실행 작업은 등록하지 않음. 재부팅 후 `start_remote.bat` 실행 필요.

## 검증

- Python 테스트 37개 통과: 기존 29개와 게이트웨이 인증·로그아웃·스트리밍·요청 격리 테스트 8개.
- 구동 시뮬레이션 및 선별 화면 JavaScript 회귀 검사 통과.
- 실제 외부 HTTPS 주소에서 익명 메인 요청은 로그인으로 이동(302), 익명 설정·터미널 API 요청은 차단(401), 로그인 화면은 정상 응답(200).
- 비밀번호 로그인 성공(303), 인증 후 메인 화면 및 상태 API 응답(200), 실시간 SSE 데이터 수신 확인.
- 외부 출처의 변경 요청 차단(403).
- 로그인 화면 브라우저 표시 확인: `261022_외부접속_로그인.png`.
- 실제 MCU 동작, 모터 구동, 음성 API 유료 호출, 외부 마이크 권한 및 입력 시험은 수행하지 않음.

## 운영 조건

이 PC와 메인 프로그램·게이트웨이·터널이 실행 중이어야 접속 가능함. 로컬 LAN 및 MCU 통신 경로는 기존대로 유지함. 원격 사용법은 `ARD_MAIN/REMOTE_ACCESS.md` 참조.
