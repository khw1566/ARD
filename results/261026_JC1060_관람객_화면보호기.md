# JC1060 관람객 화면 보호기

- 기본 무조작 30초. 설정 → 화면 보호기에 15초 / 30초 / 1분 / 5분 / 화면보호기 없음 추가.
- NVS `ard-ui/saver_sec`에 저장. 미저장·잘못된 값은 30초. 저장 실패 시 기존 선택 유지.
- 상단 및 설정에서 수동 진입. 자동 진입 없음으로 설정해도 수동 진입 가능.
- 참여 안내와 도움말 4개를 5초 간격으로 순환. 간단한 이동 도형·페이지 점·진행 표시줄 포함. 실제 장치 구동과 별개의 안내 애니메이션.
- 안내 화면 터치 후 손을 떼면 메인 탭으로 복귀. 복귀 제스처는 제어 버튼에 전달하지 않음.
- 비상정지 상단 유지. 진입 시 수동 연속구동 해제 및 PTT 종료. 누르고 있는 입력은 자동 진입에서 제외. 승인·보드 알림 우선.
- 별도 `main/ui_screensaver.cpp/.h`와 기존 UI/설정 연결. 한국어 번역 및 글꼴 재생성. 기존 사용자 변경은 유지.

## 소스 확인

- preflight: ESP32-P4 / ESP-IDF 5.5.5 / LVGL 9.2.2. 새 소스는 CMake 목록에 있음. 기존 컴파일 데이터베이스에는 아직 없으며 사용자 빌드 때 갱신 필요.
- 설치된 LVGL 헤더 및 입력 처리 소스로 inactivity, activity reset, input state, release, tab switching API를 대조.
- 번역 검사: 322개 키 중 4개 기존 불일치(PID: ON, PID: OFF, Ready. Start sorting from the PC dashboard., PC update %s). 새 화면 보호기 문구는 일치.
- 글꼴 생성: 305자 × 3크기, 비트맵 259,004 bytes. 글꼴 생성은 Python 데이터 생성이며 컴파일하지 않음.
- 펌웨어·시뮬레이터·호스트 실행파일 빌드 및 플래시를 실행하지 않음. 렌더링과 실제 기기 동작은 미확인.

## 실제 기기 확인

1. 미설정 상태에서 마지막 터치 후 약 30초에 진입하는지 확인.
2. 각 시간 옵션과 자동 진입 없음 확인. 재부팅 후 선택 유지 확인.
3. 상단/설정 수동 진입 후 4개 도움말 순환과 애니메이션 확인.
4. 버튼 위치 위를 터치해 복귀해도 제어가 실행되지 않는지 확인.
5. 조이스틱/TALK를 오래 누르는 동안 자동 진입하지 않는지 확인.
6. 비상정지 접근과 승인·보드 알림 우선 표시 확인.
