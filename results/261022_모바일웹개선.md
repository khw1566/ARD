# 모바일 웹 화면 개선

작성일: 2026-10-22 (KST)

작성자: Codex

접속 주소: https://ard.audreaming.com

## 적용 사항

- 기존 ARD 제어판의 테마와 PC 배치를 유지하고 1100px 이하에서 모바일·태블릿 배치를 적용함.
- 고정 화면 높이 대신 페이지 세로 스크롤을 사용함.
- 장비 상태와 선별 단계를 좌우로 넘겨 볼 수 있도록 구성함.
- 하단에 선별·카메라·구동·설정 메뉴를 추가함. 메뉴는 화면만 전환하며 장비 명령을 전송하지 않음.
- 선별 영상과 3D 모니터, 구동 화면과 조작 패널을 한 열로 배치함.
- 주요 터치 버튼은 최소 44px, 하단 메뉴와 로그인 버튼은 48px 높이를 적용함.
- 입력 글자를 16px로 유지하고 휴대폰에서 버튼 글자를 작게 줄이는 대신 줄바꿈함.
- 화면 안전 영역과 동적 뷰포트 높이를 반영함. 로그인은 가로 화면과 키보드 표시 상황에서도 세로 스크롤 가능함.
- 3D 구동 화면은 Pointer Events로 드래그를 처리하며 세로 페이지 스크롤을 허용함.
- 설정·터미널·시험 화면의 작은 화면 배치를 조정함. 긴 시험 결과 표는 표 안에서 좌우로 스크롤함.
- 키보드 초점 표시 및 동작 감소 설정을 반영함.

## 검증

- 실제 Chrome 브라우저에서 320·390·768·1024·1440px의 메인·설정·터미널·시험 화면을 확인함.
- 좁은 화면에서 발견한 설정 통계 및 시험 표 넘침을 수정하고 다시 확인함.
- 외부 로그인 화면은 320px 세로, 390px 세로, 844px 가로 크기로 확인함.
- 모바일 하단 카메라 메뉴의 화면 전환과 선택 표시를 확인함.
- Python 테스트 37개 통과. 구동 시뮬레이션 및 선별 화면 JavaScript 회귀 검사 통과.
- 변경 JavaScript 구문 검사 및 Git 공백 검사 통과.
- 실제 외부 도메인에서 비밀번호 보호, 모바일 CSS 전달, 메인·설정·터미널·시험 페이지, 상태 API 및 실시간 SSE 데이터 수신을 확인함.
- 실제 iPhone·Android 기기의 터치·키보드·마이크 및 MCU 실기기 동작을 시험한 결과는 아님. 화면 크기를 조정한 Chrome 검증임.

검증 캡처는 `output/playwright/`에 로컬 보관함. 브라우저 인증·검사 기록은 Git에서 제외함.
