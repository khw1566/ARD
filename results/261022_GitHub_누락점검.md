- 내부 ARD에서 동일 내용의 추적 사본을 찾지 못한 파일: 14개.

- ESP-IDF와 main의 Arduino/PlatformIO 프로젝트는 구조와 구현이 다르므로 파일 이름 차이만으로 기능 누락을 단정하지 않음. 빌드 및 기능 테스트는 이번 파일 점검 범위에 포함하지 않음.

## 해석

- 내부 ARD는 최신 main의 파일을 보유하지만, 바깥 ARD_MAIN과 자동으로 연결되지 않음.
- 바깥 ESP-IDF 작업의 수정 파일과 미추적 파일은 현재 원격 ard-v1에 반영되지 않은 로컬 작업임.
- 사본을 찾지 못한 파일은 원격 ard-v1 커밋에 존재하므로 그 커밋에서 복구할 수 있음. 의도적인 삭제인지 별도 확인이 필요함.
