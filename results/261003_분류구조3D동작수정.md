# DriveMCU 분류구조 3D 동작 불일치 수정

## 기준 자료
사용자 지정 대한기계학회 최종보고서 PDF의 6쪽(인쇄 5쪽), 2.3절 및 수식 3~6을 확인했다. 보고서는 같은 방향 입력의 합으로 Yaw를, 반대 방향 입력의 차로 Roll을 계산한다. 보고서의 베벨 치수비 n은 별도 기구 파라미터이며 이번 수정은 기존 프로그램의 감속비 환산 체계를 유지한다.

## 확인된 문제
- DriveMCU는 df=(+,-), db=(-,+)로 전도, dr=(+,+), dl=(-,-)로 선회한다.
- PC 서버와 웹 animate는 합을 Roll, 차를 Yaw로 계산하여 명령의 의미를 뒤집었다.
- 자동 선별 역변환도 Y 입력이 Roll-Yaw로 되어 있었다.
- 버튼의 직접 각도 증가와 서버 drive_update가 같은 동작의 모델 상태를 각각 수정했다.
- 트레이의 회전 중심이 바닥 원점이고 선회가 전도의 자식이어서 복합 동작의 배출 방향이 잘못 표현됐다.

## 변경
- app.py의 상태 계산: Yaw=(X+Y)/2, Roll=(X-Y)/2. 감속비 환산은 기존 방식 유지.
- df/db/dr/dl 직접 명령도 DriveMCU와 동일한 부호 및 기본 200스텝으로 상태 계산.
- simulation-drive.js의 순변환과 역변환을 동일한 규칙으로 정리.
- 수동 동작은 서버 drive_update에서 목표각 갱신. 중복 로컬 가산 제거.
- 모델 계층을 레일 캐리지 → 선회 → 전도로 변경하고 축 높이 3.5에 회전 중심 배치.
- 기존 수거함 배치에 맞춰 시계방향 방위 90도는 음의 X측으로 전도되도록 렌더링 좌표 변환.
- 긴 프레임 간격에서 보간 계수가 1을 초과해 목표각을 넘지 않도록 제한.
- index.html의 시뮬레이션 스크립트 캐시 버전 갱신.
- DriveMCU의 실제 모터 명령 및 펌웨어는 수정하지 않음.

## 검증
- tests/test_drive_state.py: 5개 테스트 통과. 같은/반대 방향, 직접 명령, 선회 후 전도 및 복귀, 서로 다른 감속비와 단일축 명령 확인.
- tests/test_drive_simulation.cjs: 실제 JS 코드를 VM에서 실행하여 순변환·역변환, 방향, 중복 가산 방지, 원점 복귀, 긴 프레임 보간 확인.
- Node 문법 검사 통과.
- 실제 웹 브라우저의 WebGL 화면 및 하드웨어 구동 비교는 아직 수행하지 않음.

## 적용 및 범위
PC 메인프로그램을 재시작하고 웹 페이지를 새로고침한다. 전도와 선회 버튼을 기존과 동일한 작은 스텝으로 비교한다. 이번 검증은 소프트웨어 계산 및 상태 흐름에 대한 것이며 실제 모터 위치 계측은 아니다. MCU 하트비트에는 회전축 실측 위치가 없어 명령 기반 예측을 표시한다. Z 레일의 기존 스텝/mm 환산과 자동 선별 이동량은 이번 변경에서 유지했으며 실측 보정은 별도 확인이 필요하다.
