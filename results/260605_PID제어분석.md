# DriveMCU Z축 PID 제어 시스템 구성 및 상세 분석

## 상세 제어 루프 설계
1. **입력 신호 필터링**: ToF 센서(VL53L0X)로부터 원시 데이터를 받은 후, 고주파 노이즈를 제거하기 위해 **5-샘플 이동 평균 필터(Simple Moving Average)**를 통과시켜 부드러운 피드백 값(`lastDistance`)을 얻습니다.
2. **비교기 및 오차 계산**: 목표 거리(`targetRailDist`)와 피드백 값을 비교하여 오차(Error = Target - Feedback)를 mm 단위로 산출합니다.
3. **데드존(Deadzone) 분기**:
   - 오차가 **±2.0mm 이내**이면 불필요한 떨림(Hunting)을 예방하기 위해 모터를 완전히 정지시키고 적분값(`integralRail`)을 즉시 0으로 초기화합니다.
   - 오차가 2.0mm보다 크면 PID 연산을 시작합니다.
4. **PID 컨트롤러 (50ms 동작)**:
   - **비례 제어(P)**: `Kp = 0.3`. 오차가 3.0mm 미만으로 줄어들면 감속을 부드럽게 만들기 위해 Kp를 50% 수준으로 자동 감쇠하는 **소프트 랜딩(Soft Landing)**을 수행합니다.
   - **적분 제어(I)**: `Ki = 0.01`. 적분 누적의 발산을 막기 위해 오차가 10.0mm 미만인 범위에서만 적분을 누적하며, 누적 범위를 **-50에서 +50** 사이로 단단히 묶는 **Anti-Windup** 장치가 적용되어 있습니다. (10.0mm 이상이면 적분값을 0으로 리셋)
   - **미분 제어(D)**: `Kd = 5.0` (스케일 조정 0.01 반영). 오차의 변화 속도를 감쇠하여 급격한 구동을 억제합니다.
5. **물리 단위 변환**: 계산된 PID 제어값 합산에 물리 스케일링 계수(`stepsPerMmZ` = 43.48)를 곱하여 mm 단위를 모터의 실제 이동 스텝(Step)으로 변환합니다.
6. **모터 드라이버 구동**: 최종 산출된 `moveDelta`만큼 AccelStepper 라이브러리를 통해 Z축 스텝 모터를 `moveTo`로 정밀 구동합니다.

## 갱신된 D2 블록도 특징
- **표준 피드백 제어 루프 레이아웃**: 피드백 제어 공학 표준 형태인 `목표값 -> 비교기 -> 제어기 -> 물리계 -> 센서 -> 필터 -> 비교기` 순서의 루프를 한눈에 볼 수 있도록 도식화했습니다.
- **병렬 PID 구조**: P, I, D 가 각각의 수직 방향 병렬 경로로 나누어져 연산된 후 합산되는 구조를 직관적으로 나타냈습니다.
- **데드존 분기 표시**: 데드존(±2.0mm) 조건에 의해 모터 정지로 분기되는 흐름을 빨간색 점선으로 강조 표시했습니다.
- **발표용 최적화**: 텍스트 상자 크기를 줄이고, 꼭 필요한 세부 매개변수 값(Kp, Ki, Kd, Steps/mm 값 등)만 큰 폰트로 배치해 컴팩트하면서도 가독성을 극대화했습니다.
