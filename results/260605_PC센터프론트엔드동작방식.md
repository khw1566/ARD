# 작성자: AI Assistant (Antigravity)

## 1. 개요 및 아키텍처 (Architecture Overview)
ARD 프로젝트의 PC Center 프론트엔드는 React나 Vue.js 같은 무거운 최신 프론트엔드 프레임워크를 배제하고, **순수 웹 기술(Vanilla JavaScript, HTML5, CSS3)**만을 사용하여 구축된 **단일 페이지 애플리케이션(SPA, Single Page Application)**입니다. 

전체 레이아웃과 뷰 컴포넌트를 담고 있는 방대한 `index.html` 파일과, 모든 동적 로직과 상태 제어를 관장하는 `main.js` 파일이 코어 역할을 합니다. 이 방식은 브라우저 렌더링 성능을 극대화하고 라이브러리 의존성을 최소화하여 다양한 제어 MCU 보드(ImageSender, HMI, Drive, Control, Robot3Axis)와의 즉각적인 데이터 연동에 초점을 맞추고 있습니다.

## 2. 주요 기술 스택 및 외부 라이브러리 (Tech Stack & Libraries)
프레임워크를 배제한 대신 시각적 효과와 데이터 모니터링을 위해 특정 기능에 특화된 경량 라이브러리들을 활용하고 있습니다.
- **Three.js**: 3D 시뮬레이션 환경을 구축하여 하드웨어 보드(예: 3축 로봇 시스템, 모터 구동 모듈 등)의 물리적 상태와 실시간 움직임을 웹 브라우저 상에 시각적으로 렌더링합니다.
- **Chart.js**: 각종 센서 데이터(온도, 변위량 등)의 변화를 실시간 그래프 형식으로 모니터링하기 위해 사용됩니다.
- **Web Audio API**: `AudioContext` 등을 활용하여 PC 자체의 마이크 오디오나 시스템 사운드를 캡처(Loopback)하고 이를 가공하여 백엔드를 거쳐 무선 스피커 모듈로 스트리밍하는 고급 오디오 처리 기능이 포함되어 있습니다.

## 3. 핵심 동작 방식 및 주요 기능 (Core Operations)

### 3.1 탭 기반 라우팅 및 뷰(View) 전환
`main.js` 내의 `switchTab()` 및 `switchSubTab()` 함수를 통해 가상의 페이지 전환 로직을 구현합니다. 사용자가 상단 헤더의 특정 MCU 보드 상태 박스를 클릭하면, 해당 보드와 관련된 제어 패널(DOM 요소)만 화면에 표시(`display: block` 또는 `flex`)되고 나머지는 숨김(`display: none`) 처리됩니다. 화면 전환 시 Three.js 캔버스 리사이징이나 카메라 렌더러 정지/시작 등 최적화 과정이 자동으로 수행됩니다.

### 3.2 실시간 데이터 동기화 및 폴링(Polling)
프론트엔드는 백엔드(Python Flask/FastAPI 기반)와 통신하며 시스템 상태를 주기적으로 업데이트합니다. 
- `/api/status` 와 같은 엔드포인트를 호출하여 각 MCU의 IP 주소, 신호 강도(RSSI), CPU 온도 등의 상태 값을 받아오고 동적으로 HTML 요소(글자색, 게이지 애니메이션 등)를 변경합니다.
- 자체적인 로그 시스템(`addLog` 함수)을 구축하여 백엔드에서 일어나는 이벤트(명령 전송 성공 여부, AI 응답 등)를 프론트엔드 터미널 창(Log Container)에 실시간으로 출력합니다.

### 3.3 복합 미디어 및 AI 제어 통합 센터
`controlmcu-tab` 내부에는 단순한 하드웨어 스위치를 넘어선 다양한 소프트웨어 제어 기능들이 집약되어 있습니다.
- **다중 미디어 스트리밍**: 로컬 MP3 플레이어, 글로벌 라디오(URL 기반) 스트리밍, 유튜브 오디오 추출, PC 데스크톱 오디오 미러링 기능을 지원합니다. 프론트엔드에서는 3-Band 파라메트릭 이퀄라이저 UI(Bass, Mid, Treble)를 조작하여 실시간으로 서버에 EQ 값을 전송합니다.
- **AI 비전 및 챗봇 연동**: 비전 카메라로 인식한 객체/유형/재질의 결과를 HUD(Head-Up Display) 스타일의 인터페이스로 출력하며, 시스템의 AI 페르소나 텍스트를 웹 편집기에서 실시간으로 수정하여 서버로 저장하는 기능(`loadPersonaFile`, `save-persona-btn`)을 갖추고 있습니다.

### 3.4 다국어 지원 (i18n) 및 설정 관리
브라우저의 `localStorage`를 활용하여 한국어와 영어를 지원하는 다국어 처리 로직이 내장되어 있습니다. `updateLanguage()` 함수를 통해 HTML의 `data-i18n` 속성을 가진 모든 DOM 요소의 텍스트가 즉각 변경됩니다. 또한 해상도, 카메라 모델(OV2640 등), JPEG 품질 등의 설정을 변경하면 프론트엔드에서 즉시 입력 폼 유효성 검사 및 UI 제한(예: 특정 카메라 선택 시 해상도 제한)을 거친 후 `/api/config` 를 통해 서버에 반영합니다.

## 4. 디자인 및 시각적 사용자 경험 (UX/UI Design)
- **사이버네틱 대시보드 테마**: 다크 모드를 기본으로, 네온 톤의 Cyan(청록색)과 Emerald(에메랄드색) 계열의 포인트 컬러를 적극 사용합니다.
- **마이크로 인터랙션**: CSS3의 `@keyframes` 애니메이션을 적극 활용하여 버튼 호버, 펄스 이펙트(`pulse-cyan`), 오디오 재생 중 회전하는 CD 아트워크(`spin-cd`), 서버 종료 버튼(`shutdown-ring-progress`) 등 정교하고 매끄러운 시각적 피드백을 제공함으로써 고급스럽고 미래지향적인 컨트롤 룸의 분위기를 연출합니다.
