# 메인 프로그램: 현재 위치 원점 설정, 카메라 탭 잘림, Gemini 기본 모델

## 1. 현재 위치를 원점으로 설정
DriveMCU에는 현재 위치를 0으로 바꾸는 명령이 없었습니다(`home`은 0으로 이동만 함). 새 명령 `zero`를 추가했습니다.

| 위치 | 내용 |
|---|---|
| DriveMCU `motion.*` | `motion_set_origin()`: 모든 축이 정지 상태일 때 X/Y/Z 현재 위치를 0으로 설정. 이동·조그·귀환·대기 큐가 있으면 거부 |
| DriveMCU `commands.cpp`, `CommandValidation.h` | `zero` 명령, 도움말, 검증 목록 |
| PC `backend/app.py` | `update_motor_state`가 `zero`를 `home`처럼 처리해 위치 추정을 0으로 초기화 |
| PC `sidebar.html`, `simulation-drive.js`, `translations.js` | 구동 탭(디스크 제어 카드)과 선별 탭 사이드 카드에 "현재 위치를 원점으로 설정" 버튼. 확인 창 후 `zero` 전송, 성공하면 3D 모델을 애니메이션 없이 0으로 맞춤 |

JC1060 조그와의 관계: PC 명령이 들어오면 JC1060 조그는 해제되고, 다시 RE-ARM할 때 보드 위치를 새 기준으로 읽으므로 위치 추정이 이중으로 빠지지 않습니다.

## 2. 카메라 탭 이미지 잘림
원인: `#latest-image`가 `height: 100%`였지만 컨테이너 높이가 정해지지 않아 이미지 원래 비율 높이로 컨테이너를 늘렸습니다. 1920×1080 화면에서 800×600 이미지가 1058px 높이가 되어 화면 아래가 잘렸습니다(1366×768, 2560×1440도 같음).
수정: 이미지를 `position: absolute; inset: 0` + `object-fit: contain`으로 바꿔 컨테이너(오른쪽 패널 높이)에 맞춥니다. 렌더링 비교에서 이미지 전체가 화면 안에 들어오는 것을 확인했습니다.

## 3. Gemini 2.5 Flash-Lite 기본값
코드 기본값은 이미 `gemini-2.5-flash-lite`였지만, `backend/.env`에 `GEMINI_MODEL=gemini-3.1-flash-lite`가 저장돼 있어 덮어쓰고 있었습니다(설정 화면에서 모델을 바꾸면 .env에 저장됨). .env 값을 `gemini-2.5-flash-lite`로 바꿨습니다.
