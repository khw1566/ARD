# ARD HMI UI 복구 및 Git 버전 관리 구축 결과 보고서
본 보고서는 ARD HMI 대시보드의 화면 틀어짐/잘림 반응형 교정 및 모듈화 이전의 오디오/미디어 서브탭 기능 복구, 그리고 좀벌레 바이너리 필터링을 거친 청정 Git 버전 관리 체계 수립 실적을 기록합니다.

## 1. HMI UI/UX 반응형 고도화 실적
- 상단 보드 상태 박스들의 ONLINE/OFFLINE 전환 시 덜컹거림(Layout Shift) 현상을 제거하기 위해 상시 68px 경계 박스 레이아웃을 확립했습니다.
- 마지막 'PC IP & 모드 스위치' 상태 탭의 텍스트가 경계를 침범하고 화면 전체를 가로지르며 아래 카드를 뭉개던 현상을 교정하기 위해 다른 5개 탭과 동일한 status-box 클래스 위계로 완벽하게 규격화 및 다운사이징했습니다.
- 세로 뷰포트가 제한된 저해상도 노트북 화면(예: 1280x800)에서도 카메라 피드 이미지와 사운드 제어 카드가 비율에 맞춰 지능적으로 축소(Flex Shrink)되도록 min-height: 0 !important 속성을 부여하여, 화면 하단의 채팅 입력 필드와 전송 버튼이 단 1픽셀도 잘리지 않고 상시 완전 노출되도록 보장했습니다.

## 2. 모듈화 누락 오디오 및 미디어 기능 복원
- `main.js`의 `switchTab` 엔진 조건분기를 대대적으로 보강하여 drivemcu, robot3axismcu, imagesendermcu, soundmcu 각 탭 선택에 맞춰 좌측 컬럼 요소(Live Feed, 3D 뷰어, 음성/미디어 센터)가 가장 세련되고 집중도 높은 레이아웃으로 부드럽게 자동 전환되도록 복구 완료했습니다.
- SoundMCU HMI UI 보드 활성화 시 Parametric EQ 믹싱, 마이크 볼륨 스케일러, 실시간 인터넷 라디오 및 오디오 다운로더가 UI와 오차 없이 온전히 기능함을 실증 검증했습니다.

## 3. 청정 Git 버전 관리 체계 수립 실적
- 브라우저 끌어다 놓기 업로드 시 25MB 파일 한계로 발생하던 문제를 근본 분석하여 .pio 컴파일 디렉토리, venv 파이썬 가상환경, pycache 임시 저장 캐시 등 소스코드가 아닌 대용량 벌룬 바이너리들을 색출했습니다.
- 강력한 차단 규칙을 품은 `.gitignore` 필터를 수립한 후, 기존 450MB가 넘게 꼬여 있던 깃 데이터베이스 캐시를 완전히 폭파(Purge)하고 100% 청정 소스 코드(약 1MB 수준, 21,531줄)만 추려 낸 무결한 'Initial commit'을 완수했습니다.
- GitHub 원격 저장소(`https://github.com/khw1566/ARD`)를 로컬에 origin 링크로 완전 결속시켰습니다.

## 4. 최종 형상 검증 결과
- FHD 대화면 및 창 크기를 줄인 모든 반응형 시뮬레이션 환경에서 UI 겹침, 틀어짐, 스크롤 막힘이 0%로 완벽하게 제어되며, Git Push를 통해 안전하게 형상 백업이 가동됨을 증명했습니다.
