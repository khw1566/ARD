# MCP 서버 구성 및 아키텍처 (Configuration)
- 프레임워크: `FastMCP` 라이브러리를 활용한 모델 컨텍스트 프로토콜(Model Context Protocol) 기반 독립 서버 구성
- 네트워크 연결: PC Center 코어 웹서버(`app.py`, `http://localhost:5000`)를 대상으로 HTTP REST API(`requests` 모듈) 요청을 발송하는 프록시 형태로 구현
- 주요 목적: 외부의 대규모 언어 모델(LLM, 예: Cursor IDE, Claude Desktop 등)이 로컬 로봇 하드웨어에 직접 명령을 내리고 실시간 센서 데이터를 읽을 수 있도록 표준화된 인터페이스 제공

# 정보 조회 상호작용 (Information Interaction)
- 시스템 리소스 정의(`ard://system/status`): 로봇 시스템 전체의 상태값(각 보드의 IP, 연결 상태, 센서 값, 서보/스텝 모터의 각도 등)을 JSON 형태로 패키징하여 제공
- 상태 조회 도구(`get_robot_status`): 인공지능이 로봇의 현재 상황(온도, 오프라인 여부 등)을 파악하고자 할 때 호출하는 Tool로, 상태 데이터를 실시간으로 가져옴

# 제어 및 명령 상호작용 (Control Interaction)
- 구동부 제어(`control_drive_motor`): 휠베이스 이동을 담당하는 `DriveMCU`에 직진, 후진, 회전 등의 주행 텍스트 명령 하달
- 로봇팔 다관절 제어(`move_3axis_robot`): X(회전), Y(전후), Z(상하)축에 대한 상세 물리적 위치 좌표와 절대값 여부(`absolute`)를 인자로 받아 `Robot3AxisMCU` 제어
- 공압 시스템 제어(`control_pneumatic_gripper`): 로봇팔 끝단의 릴레이(Solenoid Valve)를 제어하여 진공 그리퍼의 흡착(close) 및 해제(open) 수행
- 비전 센서 제어(`trigger_image_sensor`): `ImageSenderMCU`에 촬영 명령(`capture`)을 보내어 분석용 이미지 생성 유도
- 일괄 원점 복귀(`homing_all_robots`): 시스템 초기화를 위해 `DriveMCU`와 `Robot3AxisMCU` 등 모든 하드웨어 기구부를 캘리브레이션 0점(Home)으로 동시 복귀시키는 기능 제공
