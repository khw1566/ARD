# 최종 결과물 추가 게시

2026-10-27. 직전 검토에서 최종 CG 영상·자막·크레딧이 제외되어 있음을 알렸고,
사용자가 이어서 커밋·푸시를 지시했다. 이 기록은 앞선 소스·CAD 게시의 후속 작업이다.

- 대상: `github.com/khw1566/ARD` / `ard-v1`. 시작 커밋 `cb30e13`.
- `output/ard-cg/final/`의 최종 영상·음성·자막·크레딧·이미지·품질 JSON을 포함한다.
- 해당 폴더의 MP4/WAV는 Git LFS로 관리한다. 기존 이력을 다시 쓰거나 다른 브랜치에 병합하지 않는다.
- 이전 버전을 삭제하지 않고 모두 보존했다. 최신 전체 발표 영상은 `ARD_FullPresentation_1080p_v2.mp4`다.
- `config_manager.py`의 빈 줄에 추가된 공백만 정리했다. 실행 코드 변경은 없으며 기존 커밋과 일치한다.
- 비밀 설정, 원본 음성 학습 자료·모델, 다운로드 음원 원본, 빌드·렌더 캐시의 제외 규칙은 유지한다.

## 확인

- 최종 폴더 파일 41개(사용 안내 README 포함), 합계 약 662.95 MiB.
- MP4 5개, WAV 3개에 대해 ffprobe 메타데이터 읽기 성공. 전체 발표 2개는 각각 180초,
  CG 영상은 135초, 실물 안정화 영상 2개는 각각 42.3초다.
- 텍스트 및 파일 원문에 대한 알려진 키 값·키 패턴 검사를 수행했다.
- Git LFS를 이 저장소에만 설정했다. Git의 staged 미디어는 작은 LFS 포인터이며 실제 파일은 로컬 LFS 객체로 보존한다.
- 이 작업은 게시 범위 변경이다. 펌웨어 빌드·플래시나 영상 재인코딩은 수행하지 않았다.

재다운로드 시 Git LFS가 필요하다. 포인터만 보이면 `git lfs pull`을 실행한다.
