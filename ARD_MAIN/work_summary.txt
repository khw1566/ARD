[최근 진행 상황 요약 - 2026.04.23]

1. Z축 레일 제어 시스템 고도화
   - PID 제어를 폐기하고 실용적인 "피드백형 이산 스텝 제어(Step-and-Check)" 방식으로 전환.
   - 실측 데이터 기반 스텝 비율 수정: 1000 steps = 23.0 mm (기존 비율에서 정밀 보정).
   - 정지 후 300ms 대기 로직을 통해 ToF 센서 값의 신뢰성 확보 및 ±1.5mm 데드존 적용.

2. GPS 원격 제어 기능 추가
   - DriveMCU의 GPS 모듈을 PC 센터에서 실시간으로 ON/OFF 할 수 있는 토글 기능 구현.
   - 기본값을 OFF로 설정하여 전력 효율 및 시스템 로그 정돈.

3. PC 센터 UI/UX 최적화 및 레이아웃 복구
   - 사용자의 선호에 맞춰 "로그창"과 "실시간 차트"를 하단 가로(Flex-row) 배치로 복구 (높이 200px 고정).
   - 시뮬레이션 각도표(HUD) 너비를 320px로 축소하고 폰트/패딩을 조절하여 컴팩트한 디자인 완성.
   - 차트 그래픽이 박스를 이탈하던 CSS 버그 수정 및 절대적 고정 배치 적용.

4. 시스템 로직 및 버그 수정
   - 감속비(Gear Ratio) 적용 로직 수정: 실제 출력축 이동량에 맞춰 모터 스텝이 자동 증폭되도록 개선.
   - 서버 종료 시 소켓 포트를 즉시 반환하지 않던 "좀비 서버" 이슈 해결 (_thread.interrupt_main 사용).
   - DriveMCU 명령 파싱 우선순위를 재정립하여 특정 명령이 무시되던 현상 해결.
