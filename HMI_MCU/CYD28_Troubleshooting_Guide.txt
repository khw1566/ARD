# CYD28 (ESP32-2432S028) 디스플레이 및 터치 트러블슈팅 가이드

## 1. 개요
CYD (Cheap Yellow Display) 2.8인치 보드에서 화면이 하얗게 멈추거나, 터치가 먹통이 되고, 터치 좌표가 엉뚱하게 나오는 현상에 대한 원인과 완벽한 해결 방법을 정리한 문서입니다.

## 2. 하드웨어 핀맵의 진실 (가장 큰 실수 원인)
일반적인 ESP32 디스플레이 예제들은 화면과 터치가 같은 SPI 버스(핀)를 공유한다고 가정합니다. 하지만 **CYD28 보드는 디스플레이와 터치 패널이 완전히 분리된 핀**을 사용합니다.

*   **디스플레이 SPI 핀 (하드웨어 HSPI 사용):**
    *   MOSI: 13
    *   MISO: 12
    *   CLK: 14
    *   CS: 15
*   **터치스크린 SPI 핀 (별도의 소프트웨어 SPI 필요):**
    *   MOSI: 32
    *   MISO: 39
    *   CLK: 25
    *   CS: 33
    *   IRQ: 36 (인터럽트 핀)

## 3. 발생했던 문제와 원인 분석
### 문제 1: 터치 Z값이 항상 4095로 나오고 X, Y가 0인 현상
*   **원인:** `XPT2046_Touchscreen` 기본 라이브러리는 하드웨어 SPI(보통 VSPI)를 사용하려고 시도합니다. 따라서 핀 선언 없이 `touch.begin()`을 호출하면 보드의 터치 핀(32, 39, 25)이 아닌 엉뚱한 핀을 읽게 되어 MISO가 항상 HIGH(1) 상태로 인식되어 최대값 4095가 반환됩니다.

### 문제 2: 디스플레이 화면이 멈추거나 깨지는 현상
*   **원인:** 디스플레이가 사용하는 HSPI 버스(13, 12, 14)에 강제로 터치를 얹으려고 `SPI.begin()`을 `loop()` 등에서 지속적으로 덮어쓰면, 디스플레이와 터치가 버스 충돌을 일으켜 화면이 깨지거나 멈춥니다.

### 문제 3: 터치 위치가 90도 틀어지거나 화면 밖으로 인식되는 현상
*   **원인:** CYD 보드의 세로 모드(Portrait, 240x320)와 가로 모드(Landscape, 320x240) 간의 해상도 축 변경을 라이브러리가 자동으로 처리하지 못합니다. 

## 4. 완벽한 해결책

### 1) 올바른 터치 라이브러리 사용
기본 `XPT2046_Touchscreen` 대신, CYD 보드 전용으로 제작되어 지정된 핀으로 소프트웨어 SPI(Bit-banging)를 수행하는 **`CYD28_TouchscreenR`** 라이브러리를 사용해야 합니다. (이 라이브러리는 하드웨어 SPI를 건드리지 않으므로 화면과 충돌하지 않습니다.)

### 2) 세로 모드(Portrait) 해상도 스왑 트릭
세로 모드(240x320)로 사용할 때, 터치 라이브러리 내부의 맵핑 공식을 맞추기 위해 생성자에는 가로 모드 해상도로 입력하고 Rotation을 0으로 줍니다.
```cpp
// 가로폭과 세로폭을 거꾸로 (320, 240) 입력해야 X(0~240), Y(0~320)로 정상 반환됨
CYD28_TouchR touch = CYD28_TouchR(320, 240); 
```

### 3) 코드 초기화 순서 및 방법
```cpp
#include <TFT_eSPI.h>
#include "CYD28_TouchscreenR.h"

TFT_eSPI tft = TFT_eSPI();
CYD28_TouchR touch = CYD28_TouchR(320, 240); // 🚨 핵심: (320, 240) 으로 입력

void setup() {
    // 1. 디스플레이 초기화
    tft.init();
    tft.setRotation(0); // 세로 모드 240x320
    tft.invertDisplay(true); // CYD 보드는 색상 반전이 필요함

    // 2. 터치 초기화
    touch.begin(); // 라이브러리 내부에 32, 39, 25 핀이 하드코딩 되어 있음
    touch.setRotation(0); // 0번 로테이션 적용
}

void loop() {
    if (touch.touched()) {
        CYD28_TS_Point p = touch.getPointScaled();
        
        // p.x 와 p.y 가 이미 화면 픽셀 (0~240, 0~320) 단위로 자동 맵핑되어 나옴
        int touchX = p.x;
        int touchY = p.y;
    }
}
```

## 5. 결론
CYD 보드 개발 시 **"화면은 TFT_eSPI 하드웨어 SPI에, 터치는 CYD28_TouchscreenR 소프트웨어 SPI에 분리"** 하는 것이 핵심 원칙입니다.
